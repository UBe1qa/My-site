How this counts

Characters
One for each character as people see it (grapheme clusters, Unicode UAX #29). Spaces and line breaks are included.
Without spaces
The same count with spaces, tabs and line breaks left out.
Bytes
UTF-8 uses 1 byte for ASCII, 2 for most accented Latin letters, 3 for Korean, Chinese and Japanese characters and 4 for most emoji. UTF-16 uses 2 bytes for most characters and 4 for those outside the Basic Multilingual Plane. No byte-order mark is counted.
Code points
The number of Unicode code points. One visible character can be several: 👍🏽 is 2 and 👨‍👩‍👧 is 5.
X weighted length
Latin letters, digits and common punctuation count 1. Korean, Chinese and Japanese characters and most other Unicode count 2. Every link counts 23, and every emoji counts 2 however it is built. The limit is 280. The code point ranges that count 1 come from the v3 configuration of X's twitter-text library: U+0000 to U+10FF, U+2000 to U+200D, U+2010 to U+201F and U+2032 to U+2037.
Social limits
X 280 (weighted) and 25,000 for X Premium longer posts, Instagram caption 2,200 and bio 150, Threads 500, Bluesky 300 graphemes (and 3,000 UTF-8 bytes), YouTube title 100 characters and description 5,000 bytes, TikTok caption 2,200 UTF-16 units, LinkedIn post 3,000. Each was checked in the service's own documentation on 2026-10-10. YouTube tags (500 characters in total) have their own rules for commas and quotes, so they are not in the list.

Questions

How many characters is an emoji?

One, when you count characters as people see them. Inside, 👍🏽 is 2 code points and 8 UTF-8 bytes, and 👨‍👩‍👧 is 5 code points and 18 UTF-8 bytes. Tap a character under “One character, taken apart” to see its pieces.

Why is the X number different from the character count?

X uses a weighted length. Its documentation says Korean, Chinese and Japanese characters count as 2, every emoji counts as 2 and every link counts as 23, so a text of 140 Korean characters is already 280 on X.

Does a line break count as a character?

Here it counts as 1 to begin with. Some forms count it as 2 (a carriage return plus a line feed) and some ignore it, so you can switch between 0, 1 and 2.
