How this counts

Characters
One for each character as people see it (grapheme clusters, Unicode UAX #29). Spaces and line breaks are included.
Without spaces
The same count with spaces, tabs and line breaks left out.
Bytes
UTF-8 uses 1 byte for ASCII, 2 for most accented Latin letters, 3 for Korean, Chinese and Japanese characters and 4 for most emoji. UTF-16 uses 2 bytes for most characters and 4 for those outside the Basic Multilingual Plane. No byte-order mark is counted.
Code points
The number of Unicode code points. One visible character can be several: 👍🏽 is 2 and 👨‍👩‍👧 is 5.
X weighted length
Latin letters, digits and common punctuation count 1. Korean, Chinese, Japanese and most other characters count 2. Every link counts 23, and an emoji counts 2 even when it is built from several code points. The limit is 280. We follow twitter-text 3.1.0 except for emoji sequences that release does not know: it counts those piece by piece, and we count each as 2.

Questions

How many characters is an emoji?

One, when you count characters as people see them. Inside, 👍🏽 is 2 code points and 8 UTF-8 bytes, and 👨‍👩‍👧 is 5 code points and 18 UTF-8 bytes. Tap a character under “One character, taken apart” to see its pieces.

Why is the X number different from the character count?

X uses a weighted length. In the twitter-text rules, Korean, Chinese and Japanese characters count as 2, each emoji counts as 2 and every link counts as 23, so a text of 140 Korean characters is already 280 on X.

Does a line break count as a character?

Here it counts as 1 to begin with. Some forms count it as 2 (a carriage return plus a line feed) and some ignore it, so you can switch between 0, 1 and 2.
