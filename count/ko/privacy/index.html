쓰거나 붙여 넣은 글

칸칸은 글을 이용자의 브라우저 안에서 세어요. 쓰거나 붙여 넣은 글을 이 사이트가 서버로 보내거나 모으지 않고, 저장하지도 않아요. 페이지를 닫으면 글은 사라져요. 다만 뒤로 가기나 탭 복원처럼 브라우저가 입력칸의 글을 스스로 되살리는 경우가 있어요. 그때도 글은 이 기기 안에만 있어요. 회원 가입은 없어요.

기기에 저장하는 정보

이 사이트가 직접 남기는 것은 아래 항목뿐이에요. 브라우저의 사이트 데이터 지우기로 언제든 지울 수 있어요. 광고 때문에 제3자가 두는 쿠키는 아래 '광고'에 따로 적었어요.

브라우저 저장소(localStorage)에 남는 것:

  • kk.lang: 다른 언어판 안내 띠를 닫았거나 눌렀다는 표시예요. 띠를 다시 띄우지 않으려고 기억해요.
  • kk.jasoseo.on, kk.jasoseo: 자소서 화면에서 '이 기기에 저장'을 켠 경우에만 생겨요. 문항 이름, 목표 글자 수, 쓴 글, 줄바꿈 기준이 들어 있어요. 스위치를 끄거나 '저장한 글 지우기'를 누르면 바로 지워요.

탭을 닫으면 지워지는 저장소(sessionStorage)에 남는 것:

  • kk.set: 같은 탭 안에서 도구를 옮기거나 새로 고쳐도 설정이 그대로 있도록 줄바꿈 기준, 목표 숫자와 그 기준, 읽는 속도, 자소서 문항별 목표 숫자와 기준을 기억해요. 쓴 글과 문항 이름은 여기에 넣지 않아요.

이 사이트가 직접 남기는 것은 이것뿐이에요.

광고

이 사이트는 Google 애드센스로 광고를 보여 줘요. Google을 비롯한 광고 회사는 쿠키를 써서 이 사이트나 다른 사이트에 방문한 기록을 바탕으로 광고를 고를 수 있어요. 광고 때문에 Google 같은 제3자가 이용자 브라우저에 쿠키를 넣거나 읽을 수 있고, 웹 비콘(눈에 보이지 않는 작은 이미지) 같은 기술로 정보를 모을 수 있어요. Google이 이 정보를 어떻게 쓰는지는 Google 파트너 사이트에서 Google이 데이터를 사용하는 방식에 있어요. 맞춤 광고는 Google 광고 설정에서 끌 수 있어요.

방문 통계

방문 통계는 Cloudflare Web Analytics로 봐요. 어느 페이지를 몇 번 봤는지, 페이지가 얼마나 빨리 떴는지 같은 숫자예요. Cloudflare 설명으로는 쿠키나 기기 저장소를 쓰지 않아요. 이 사이트에 쓰거나 붙여 넣은 글과 설정은 여기에 실리지 않아요.

글꼴과 서버 기록

글꼴은 공개 전송망인 jsDelivr에서 받아요. 다른 웹 요청처럼 접속 IP가 전달돼요. 사이트는 Cloudflare에서 제공되고, Cloudflare는 서비스를 안전하게 운영하려고 접속 IP 같은 기본 기록을 잠시 남길 수 있어요. 어느 쪽도 이용자가 쓴 글은 받지 않아요.
