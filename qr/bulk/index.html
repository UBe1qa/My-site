Questions people ask

How many can I make at once?

Up to 1,000 lines per batch. Split bigger lists. Everything is made on this device, so time depends on its speed.

How are files named?

Write "name,URL" for URLs or "name(tab)text" for text to set a name; otherwise a name is made from the content. Text is never split at commas. Repeated names get -2, -3 added.

What happens to bad lines?

They are skipped, and a table shows which line was skipped and why. The rest are made as usual.

How do I pick the design?

Choose a preset or a design you saved under "My designs" on the generator. The same design is used for every code.

Why it is free and never expires

There are two kinds of QR code. A static code holds your link inside the image, so the phone goes straight there. There is no server in between, so nobody can switch it off. A dynamic code holds a short link of the provider and passes through their server on every scan. That lets you change the link and count scans later, but it can stop working when the subscription ends.

Staycode only makes static codes. They never expire, and the site is paid for by ads, not by you. The trade-off: you cannot change the link after printing, so for content that may change, point the code at a page you control.
