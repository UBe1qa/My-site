        Why it is free and never expires

        There are two kinds of QR code. A static code holds your link inside the image, so the phone goes straight there. There is no server in between, so nobody can switch it off. A dynamic code holds a short link of the provider and passes through their server on every scan. That lets you change the link and count scans later, but it can stop working when the subscription ends.

        Staycode only makes static codes. They never expire, and the site is paid for by ads, not by you. The trade-off: you cannot change the link after printing, so for content that may change, point the code at a page you control.

        Questions people ask

        Do QR codes made here expire?

        No. These are static codes: your link is stored inside the image, so the phone goes straight to it without passing through this site. They keep working even if this site disappears. If the page at your link goes away, though, that page will not open.

        Can I change the link after printing?

        No. If the content may change, point the code at a page you control, such as your own website or a blog post, and update that page later.

        Is it really free? Can I use it for my business?

        Yes. No sign-up, payment or watermark, and commercial use such as menus, flyers and packaging is fine. The site is paid for by ads.

        Can I see how many times it was scanned?

        This site does not count scans, because scans never pass through it. Turn on "UTM tags" for a URL and visits from the code show up separately in your own Google Analytics or Naver Analytics.

        Will it still scan with a logo?

        Adding a logo raises error correction to H (about 30%), and the finished image is read back right away. If the stamp says it scans, a decoder read it. If you see a warning, make the logo smaller.

        Where does my content or WiFi password go?

        Nowhere. The code is made inside your browser, and your content and logo are not sent to any server. Settings are not put in the page address either.

        Standards

        • ISO/IEC 18004 Model 2 QR codes, versions 1 to 40, byte mode (UTF-8). Accents, Korean and emoji work.
        • Error correction: L about 7% · M about 15% · Q about 25% · H about 30% of the code can be dirty or covered and it still reads (a logo uses up part of this).
        • The quiet zone around the code is 4 modules by default.
        • WiFi uses the WIFI: format, contacts vCard 3.0, events iCalendar VEVENT, email mailto: and SMS SMSTO:.
