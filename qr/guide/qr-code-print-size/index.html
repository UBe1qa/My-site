QR code print size: how big should it be?

Last checked October 14, 2026

For close-up scans, make the QR pattern at least 2 cm (0.8 in) wide, and plan on it scanning from about 10 times its own width. A code read from 1 m (about 3 ft) away should be around 10 cm (4 in); a banner read from 5 m should be around 50 cm. This is a rule of thumb shared on a QR provider's blog, not a formal standard, so go bigger when the code holds a lot of data.

How big for each use?

Divide the scanning distance by 10 to get the width of the pattern. The distances below are typical examples; the sizes are calculated from them.

The QR Code Generator blog (checked October 14, 2026) puts the minimum for close-up codes at 2×2 cm, readable from about 20 cm, and gives examples of a 2-inch code at about 2 feet and an 8-inch code at about 6 to 7 feet. It presents the 10:1 ratio as a rule of thumb. In dim light or where people scan at an angle, go one size up.

Why does more content need a bigger print?

More data means more modules (the small squares), so at the same printed width each module gets smaller. Generated with this site's encoder at error correction level M:

Module size is 2 cm divided by the module count. At the same 2 cm, the last code has modules about a third the size of the first, which is much harder for a camera. The generator flags a code as dense from version 10 (57×57 modules) up. To slim it down, use a shorter link, lower error correction one step, or cut the text.

Why leave a 4-module quiet zone?

A phone needs an empty border to find where the pattern begins. This generator uses a 4-module quiet zone by default and shows a warning in the scan check if you go below 4, because artwork or text touching the pattern can stop it from scanning. With a frame, the quiet zone never drops below 2 modules, so the frame never touches the pattern.

Sizes in this generator always mean the pattern itself, without the quiet zone or frame. The sticker is larger by the quiet zone. A 25×25 pattern plus 4 modules on each side is 33 modules across, so a 2 cm pattern makes a sticker about 2.64 cm wide.

Before you print

  • Give your printer SVG, PDF or EPS so the code stays sharp at any size.
  • Check that the stamp says it scans, then scan a test print with your phone from the real distance. The scan check reads the on-screen image, so print quality, light and camera can still change the result.
  • For contact details on a small card, see the vCard QR code guide for ways to keep the code simple.
