공학용 계산기
가이드소개
EN

함수표

f(x) 를 넣고 시작·끝·간격을 정하면 값 표와 작은 그래프가 나와요. g(x) 를 넣으면 두 함수를 나란히 비교해요.

  • 계산자연 표시 공학용 계산기
  • 통계평균, 표준편차 σ·s, 사분위수, 회귀식 7가지
  • 분포정규분포, 역정규, 이항, 푸아송
  • 방정식연립 2~4원, 2~4차 방정식, 부등식, SOLVE
  • 행렬·벡터4×4까지 곱·역행렬·행렬식, 내적·외적
  • 진법2·8·10·16진수, and·or·xor, 비트 수
  • 함수표f(x)·g(x) 값을 200줄까지, 작은 그래프
광고

쓰는 법

  1. f(x) 칸에 x 가 들어간 식을 써요. 예: x^2−3x+1, sin(x), 2^x.
  2. 시작값, 끝값, 간격을 넣어요. 표는 200줄까지예요.
  3. g(x) 는 비워 두어도 돼요.
  4. 삼각함수는 계산기 각도 단위(DEG·RAD)를 따라요. 표 복사 버튼으로 엑셀에 붙여 넣을 수 있어요.
