How to use

  1. Pick the input base and type a number or expression, e.g. FF + 1 in hex, or 1010 and 0110 in binary.
  2. The result appears in all four bases.
  3. Pick a word size (8, 16, 32 or 64 bits) to calculate with signed integers of that size. Overflow is reported.
  4. Division keeps the integer part (7÷2 = 3). Decimals are not allowed.
