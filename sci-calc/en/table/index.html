How to use

  1. Type an expression in x in the f(x) box, e.g. x^2−3x+1, sin(x), 2^x.
  2. Set the start, end and step. Up to 200 rows.
  3. g(x) is optional.
  4. Trig functions follow the calculator angle unit (DEG or RAD). Use Copy table to paste into a spreadsheet.
