# 떼고얼마 / Takehome Korea (salary)

한국 급여 계산기. 연봉·월급 실수령액, 연봉 실수령액 표, 퇴직금, 시급·주휴수당·최저임금, 실업급여(구직급여), 연차를 계산한다. 입력한 금액·날짜는 브라우저 밖으로 나가지 않는다(서버 코드 없음, 정적 사이트, 배포 때 빌드 없음).
- 주소: https://salary.lumenlab.page (Worker `salary`, workers.dev 끔). **한국어 `/`, 영어 `/en/`**(한국에서 일하는 외국인용. 계산 기준은 둘 다 한국). hreflang의 x-default는 영어.
- 계산기: 한국어 = 실수령액(`/`), 연봉 표(`/table/`), 퇴직금(`/severance/`), 시급·주휴수당(`/hourly/`), 실업급여(`/unemployment/`), 연차(`/annual-leave/`). 영어 = `/en/`, `/en/table/`, `/en/severance/`, `/en/hourly/`.
- 가이드 글: 한국어 6편, 영어 3편(번역이 아니라 따로 고른 주제. 퇴직금 글 한 쌍만 hreflang으로 잇는다). 소개(계산 기준 전체 표)·방침은 두 언어.
- 돈·법 주제다. **숫자는 공식 출처에서 확인한 것만** 넣는다. 값마다 출처·시행일·확인한 날을 `assets/pay-data.js`에 같이 둔다.
- 2026-10-10 제3자 평가(높음 1·중간 4·낮음 17)를 3단계에서 반영했다. 무엇을 왜 바꿨는지는 구조 문서(`context/knowledge/4-내-사이트/salary-사이트-구조.md`)에 있다.

## 폴더
- `assets/pay-data.js` 요율·상하한·최저임금·구직급여 표·연차 규칙·퇴직금 예제와 출처(`sources`). 기준 시기는 `periods`('2026-10' = 지금, '2027-01' = 다음. 각각 `starts` = 시행일). 값의 `status`: `fixed` 확정 / `resolved` 의결됨 / `carried` 다음 해 값이 아직 안 나와 지금 값을 그대로 씀(화면에 '미정' 표시). **해가 바뀌면 이 파일만 고친다.**
  - `net.pensionExemptAge`(60)·`employmentExemptAge`(65), `input`(금액 칸 읽기 기준: `manBelow`·`smallBelow`·`askAbove`), `unemployment.next`(다음 해 이직: 하한만 확정), `severance.febSkipMonth` 등 3단계에서 더한 값도 여기 있다.
- `assets/gani-2026.js` 근로소득 간이세액표(소득세법 시행령 별표 2, 2026-03-01 시행) 조회표 647줄 × 가족 1~11명. **손으로 고치지 않는다**: `_dev/data/gani-2026.json`(원본)에서 `python3 -B salary/_dev/gen_gani.py`가 만든다. 식으로 근사하지 않고 표를 그대로 찾는다. 실수령액 화면에서만 불러온다(`defer`).
- `assets/pay-core.js` 계산 로직(`PayCore(DATA, GANI)` → 브라우저에선 `window.PAY`). DOM을 모른다. 숫자 상수를 두지 않는다. **금액은 전부 정수로 계산한다**(`mulDiv`·`ceilDiv`·`roundDiv`).
  - `netPay`(실수령액. `noPension` = 만 60세 이상, `noEmployment` = 65세 이후 고용) · `compare`(지금과 다음 기준의 줄별 차이) · `salaryTable` · `validity` · `defaultPeriod`(기기 날짜가 다음 기준의 시행일부터면 다음 기준)
  - `severance`·`lastThreeMonths` · `weeklyHoliday`·`hourlyToPay`·`monthlyToHourly`·`monthlyHours` · `unemployment`·`unemploymentPeriod`·`unemploymentValidity` · `annualLeave`·`leaveDaysAfterYears` · `parseMoney`·`readKo`·`readEn`·`fmt`·`fmtDec`
  - 범위 밖 입력은 `{ ok:false, code }`로 돌려준다(조용히 틀리지 않는다).
- `assets/pay-view.js` **결과(명세서)를 HTML 글자로 그리는 곳**(`PayView(PAY, 'ko'|'en')`). DOM을 모른다. 같은 함수를 빌드(예시 결과를 첫 HTML에 미리 넣음)와 브라우저(값이 바뀔 때)가 같이 쓴다 → 처음 그림과 스크립트가 붙은 뒤의 그림이 같아 화면이 밀리지 않는다. 화면 글자(두 언어)와 예시 값(`EXAMPLE`·`STEP`·`UB_EX`)도 여기 있다. **금액 칸은 전부 `field(글자, 칸 이름)` 하나로 읽는다**(읽은 값 한 줄, 칸 옆 단위, 오류·알림).
- `assets/app.js` 화면 연결(입력 읽기, 조건 칸, 연봉 ↔ 월급 바꾸기, 앞뒤 금액, 휴대폰 붙박이 줄, 연출 셋, 다른 언어 안내 띠, 표에서 내 줄 찾기, 입력 유지, `aria-invalid`). 페이지 언어는 `<html lang>`으로만 정한다.
- `assets/style.css` 모양(토큰은 `:root`. 3단계에서 더한 것은 파일 끝), `assets/fonts/tk-<언어>-<지문>.woff2` 화면 글자만 담은 글꼴 조각(자동 생성: `_dev/font.py`)과 `OFL.txt`, `assets/ads-config.js` 광고 설정. `_headers` = 글꼴 조각을 오래 저장하라는 Cloudflare 설정.
- `_dev/build.py` **모든 HTML·sitemap.xml·rss.xml·404.html을 만든다**(`--check`는 낡았는지만 본다). 만든 파일은 손으로 고치지 않는다.
  - `_dev/calc.mjs` 빌드가 쓰는 계산값(JSON): 자료 파일 + 로직으로 구한 예시·표·글 숫자 + 미리 그린 명세서(지금 기준과, 해가 바뀐 뒤에 끼울 다음 기준). `_dev/ctx.py`가 이걸 읽어 `D`(자료)·`F`(계산값)·`G`(간이세액표)로 내준다. 원문 인용(`Q`)과 출처의 영어 이름(`SRC_EN`), 출처 링크(`src`·`srcs`. 새 탭으로 연다)도 ctx.py에 있다.
  - `_dev/texts.py` 페이지 제목·설명·입력칸 이름, 첫 화면 아래 칸(계산 기준, 출처 표), 소개, 방침. `_dev/articles.py` 가이드 글.
  - **texts.py·articles.py에 금액·요율·날짜를 손으로 적지 않는다.** 전부 `D`·`F`·`G`에서 꺼낸다(check.py가 손으로 적은 숫자를 찾는다). 법령·공단 문장은 `Q`(원문 그대로)만 인용한다.
  - `_dev/font.py` 글꼴 조각 만들기(`_dev/chars.py`가 화면 글자를 모은다. 결과는 `_dev/fonts.json`), `_dev/font_css.py`·`_dev/pretendard.css`는 공유 그림을 찍을 때만 쓴다(사이트에 올리지 않는다).
- `tests/run.mjs` 로직 시험(890개). `tests/mutate.mjs` 로직·자료를 일부러 틀리게 바꿔 시험이 잡는지 본다(171가지). `tests/site.mjs` 만든 페이지의 숫자 검산(표의 모든 칸, 미리 그린 명세서, 글의 예시 숫자, 주인 없는 숫자). `tests/ref/` 기준값(`gen_dates.py`·`gen_ub.py`가 만든 것, 고용노동부 화면에 직접 넣어 받은 값 `moel-live.json`, 평가자 대조 자료 `eval-sev.json`).
- `_dev/check.py` 정적 검사, `_dev/e2e.py` 화면 확인(Playwright), `_dev/serve.mjs` 로컬 서버, `_dev/og.py`·`og.html` 공유 그림, `_dev/icons.py` 아이콘.

## 명령어
- 전부 확인: `salary/_dev/check.sh` (로직 시험 → 빌드 최신 → 페이지 숫자 검산 → 정적 검사 → 조회표 최신). `salary/_dev/check.sh e2e [스크린샷 폴더]`는 화면 확인까지(한가할 때 10분쯤. 스크린샷 이름 앞머리는 `PRE` 환경 변수, 기본 `final3-`).
- 페이지 다시 만들기: `python3 -B salary/_dev/build.py` (node가 있어야 한다. calc.mjs를 돌린다)
- 로직 시험만: `node salary/tests/run.mjs` · 일부러 틀리게 바꿔 보기: `node salary/tests/mutate.mjs`(전부 '잡힘'이어야 한다) · 페이지 숫자: `node salary/tests/site.mjs`
- 화면 확인을 묶음만: 서버를 띄우고 `SEC=2,3 python3 -B salary/_dev/e2e.py`(1 모든 페이지 · 2 실수령액(한국어) · 3 영어·해가 바뀐 뒤·휴대폰 · 4 퇴직금 · 5 시급 · 6 실업급여·연차 · 7 연봉 표 · 8 글·광고 자리·인쇄·동작 줄이기·연출 · 9 제3자 평가에서 고친 것·글꼴)
- 로컬 보기: `node salary/_dev/serve.mjs` → http://localhost:8446 (폴더 → index.html, 없는 주소 → 404.html, `_dev`·`tests`·`_headers` 막음)
- 조회표 다시 만들기 / 최신인지: `python3 -B salary/_dev/gen_gani.py` / `… --check` · 표 전체를 주석 식으로 다시 계산해 보기: `python3 -B salary/tests/gani_formula_check.py`
- 기준값 다시 만들기: `python3 -B salary/tests/gen_dates.py`(퇴직 전 3개월·재직일수, 고용노동부 계산기의 날짜 규칙) · `python3 -B salary/tests/gen_ub.py`(구직급여, 분수 계산)
- 글꼴 조각: `python3 -B salary/_dev/font.py`(fonttools·brotli 필요. 원본은 `TK_FONT_SRC`로 주거나 jsDelivr에서 받는다). **글을 고쳐 새 글자가 생기면 check.py가 알려 준다 → 다시 돌린다.**
- 공유 그림: `python3 -B salary/_dev/og.py`(금액은 계산값에서 가져온다. 요율이 바뀌면 다시 찍는다) · 아이콘: `python3 -B salary/_dev/icons.py`
- 파이썬은 `-B`로 돌린다(폴더에 `__pycache__`를 남기지 않는다). 배포: `.deploy-actions`가 있어 main에 푸시하면 GitHub Actions가 wrangler로 배포.

## 계산 기준(화면 설명과 같아야 한다)
- **금액은 정수(원)로만 계산한다.** 요율은 분자·분모 정수(4.75% = 475/10000)로 두고 `floor(a × 분자 ÷ 분모)`. 실수(부동소수점) 곱셈·나눗셈으로 금액을 내지 않는다.
- **끝수**: 보험료 4종·소득세·지방소득세를 각각 10원 미만 버림. 국고금관리법 제47조의 끝수 계산 방식을 따른 **이 계산기의 방식**이다(`rounding.verified: 'own'`). 공단·회사가 그렇게 계산한다고 쓰지 않는다. 화면에는 "회사·공단의 계산과 몇십 원 다를 수 있어요".
- 4대 보험과 소득세는 '월급 − 비과세'(과세 대상 월급) 기준. 근거: 국민연금법 시행령 제3조, 국민건강보험법 시행령 제33조, 고용산재보험료징수법 제2조(고용보험은 법 문장까지만 확인).
- 연봉 → 월급은 ÷12(원 미만 버림), 퇴직금 포함 연봉은 ÷13(흔히 쓰는 어림이라고 화면에 밝힌다). 연 실수령액 = 월 실수령액 × 12.
- 국민연금: 과세 대상 월급의 천 원 미만을 버리고 하한·상한 안으로 맞춘 뒤 요율. **만 60세 이상은 0원**(국민연금법 제6조·제8조: 가입 대상은 18세 이상 60세 미만. 조건 '만 60세 이상이에요'. 임의계속가입으로 계속 내는 사람은 끈다). 건강보험: 요율을 곱한 뒤 본인 부담 하한·상한. 장기요양: **건강보험료** × 0.9448 ÷ 7.19(공단 식 그대로). 고용보험 0.9%, 65세 이후 새로 고용된 사람은 0(조건 '65세 이후에 새로 입사했어요'. 켜면 만 60세 이상도 같이 켜진다).
- 소득세: 간이세액표 금액 − 8~20세 자녀 공제(음수면 0) → 80·100·120% → 10원 미만 버림. 가족 11명 초과와 1,000만 원 초과는 표 주석의 식(식 금액의 원 미만을 먼저 버린다). 이 끝수 순서는 **이 계산기의 방식**이라고 화면에 적었다(1,000만 원 초과 + 80·120%에서 국세청이 어느 순서로 버리는지는 확인 못 함). 지방소득세는 그 10%.
- **해가 바뀌면**: 기기 날짜가 다음 기준의 시행일(`periods['2027-01'].starts` = 2027-01-01)부터면 **확정된 2027년 값으로 기본 계산**한다(국민연금 5.0%, 최저임금 10,700원). 건강보험 요율은 '같은 요율로 의결', 장기요양 요율·건강보험 상하한·간이세액표는 미정이라 2026년 값으로 계산하고 줄마다 꼬리표로 알린다. 첫 그림 전에 인라인 스크립트가 미리 그려 둔 다음 기준 결과(`#pre-next`)를 끼운다(화면 밀림 0).
- **기준 기간 경고**: 보고 있는 기준의 유효 기간(국민연금 요율·최저임금 12월 말, 기준소득월액 상·하한 6월 말)이 기기 날짜로 지났으면 결과 위에 "이 값은 ○○년 기준이에요. 새 기준을 확인 중이에요"가 뜬다. 새 기준이 이미 기본인데 옛 기준을 골라 보면 "지난 기준(○○년)으로 보고 있어요".
- 퇴직금: **날짜 세는 법과 끝수를 고용노동부 「퇴직금 계산」 화면에 맞췄다**(평가자가 2026-10-10에 화면에 직접 넣어 받은 값 `tests/ref/moel-live.json`이 기준). 재직일수 = 퇴직일(마지막 근무일 다음 날) − 입사일. 퇴직 전 3개월 = 3개월 전 같은 날부터 퇴직일 전날까지, 그 달에 그 날짜가 없으면 그 달 말일부터, **3개월 전이 2월이면 3월 1일부터**(5월 29일(평년)·30일·31일 퇴직). 1일 평균임금은 전 단위에서 올림(고용노동부 예제 88,641원 31전), 퇴직금은 **원 미만 반올림**. 1년 미만·주 15시간 미만은 금액 대신 조문을 보여 준다.
- 주휴수당 = min(주 소정근로시간, 40) ÷ 40 × 8 × 시급, 15시간 미만 0. 근거는 "근로기준법 시행령 별표 2의 방식(통상 근로자 주 5일·40시간 기준)으로 풀면"이라고 쓴다. 월 환산 시간 = (주 소정 + 주휴) × 365 ÷ 7 ÷ 12, 주 40시간은 고시 값 209시간, 그 밖은 식 그대로 계산하고 소수 첫째 자리까지 보여 준다. **시급 → 월급은 원 미만 올림**(최저임금 월 환산액과 같은 끝수), 월급 → 시급은 버림. 최저임금과는 **시급끼리** 견준다(왕복해도 자기 결과를 '적다'고 하지 않는다). 주 근로시간은 소수 둘째 자리까지(14.99는 14.99로 보이고 14.999는 받지 않는다). 최저임금 비교는 '기본급 기준의 단순 비교'라고 밝힌다.
- 구직급여 = max(min(평균임금, 113,500) × 60%, 1일 소정근로시간 × 이직일의 최저임금 × 80%). **3개월 임금 × 60 ÷ (날짜 수 × 100)을 한 번에 정수로 계산해 원 미만만 버린다**(평균임금을 먼저 버리지 않는다. 화면의 식도 그렇게 적는다). 날짜 수는 이직일 다음 날을 퇴직일로 보고 퇴직금과 같은 방식으로 센다(이 계산기의 방식). 1일 소정근로시간은 1~8시간 정수(공식 하한 표가 그렇다). 2025년 이직은 범위 밖. **2027년 이직은 하한을 2027년 최저임금 10,700원으로 계산(8시간 68,480원, 확정)하고 상한은 미정**이라 하루 금액·합계를 '최소'로 보여 준다. 2028년부터는 산정 기준이 바뀔 예정이라 계산하지 않는다.
- 연차: 1년 미만은 한 달이 찰 때마다 1일(최대 11일), 1년이 차면 15일, 3년부터 2년마다 +1일, 한도 25일. 한 달·1년이 찼는지는 달력의 같은 날짜로 따지고 그 날짜가 없는 달은 말일에 찬 것으로 본다(이 계산기의 방식).
- 받을 수 있는지(퇴직금 대상, 실업급여 요건)는 **판정하지 않는다.** 조문에 있는 요건만 보여 준다.

## 설계 결정
- 상징은 **급여명세서 한 장**: 줄마다 항목·금액, 손에 남는 돈 아래 이중 밑줄. 로고, 결과 종이, 루멘랩 칸(봉투와 명세서), 404, 공유 그림에 되풀이한다.
- 색: 팥색(`--main`) 한 색 + 무채색. 강조색은 실수령액·고른 것·주 단추에만. 떼는 금액(−)은 칠하지 않는다. 아직 안 정해진 값과 알림만 호박색(`--hold`), 못 읽은 칸은 붉은색(`--err`).
- 배치: 왼쪽에 넣는 칸, 오른쪽에 명세서. 답(큰 숫자)은 종이 위쪽에 요약으로, 아래에는 합계 줄로 한 번 더. 컴퓨터 왼쪽 아래에는 '앞뒤 금액과 견주기'(±100만), 다른 계산기에는 '기준 한눈에'.
- 빈 상태는 예시(연봉 4,000만 원)를 진한 회색으로 보여 주고 숫자 바로 위에 '예시' 꼬리표를 붙인다. 내 값을 넣으면 꼬리표가 사라지고 팥색이 된다.
- **금액 칸(모든 계산기가 같은 규칙)**: 칸 안 오른쪽에 단위를 늘 보여 주고(`#u-<칸 id>`), 칸 아래에 읽은 값을 늘 보여 준다. 한국어판은 단위 없는 숫자를 그 칸의 단위로 읽는다(연봉·월급·비과세·3개월 임금·상여금·연차수당 = 만 원, 시급·1일 통상임금 = 원). 만 원으로 읽으면 계산 범위를 넘는 큰 수(`input.manBelow` 이상)는 원으로 읽고 "큰 수는 원 단위로 읽어요"라고 알린다. '원'·'만'을 붙여 쓰면 쓴 그대로(그때는 옆 단위를 비운다). 그 칸에 드문 금액이면 알린다(작은 금액 `smallBelow`, 만 원으로 읽은 큰 금액 `askAbove`). 영어판은 전부 원 그대로(won). 연봉 ↔ 월급을 바꾸면 같은 돈으로 바꿔 주고(4,000만 → 3,333,333원), 고치지 않고 돌아오면 처음 쓴 글자를 되살린다.
- **입력 유지**: 계산기에 넣은 값은 이 탭의 sessionStorage(`tk.in`)에 둔다(출처를 보고 돌아오거나 새로 고쳐도 남는다. 탭을 닫으면 사라진다). 예시 상태면 지운다. 표에서 넘어온 `#a=금액`은 읽은 뒤 주소에서 지운다. 출처 링크는 새 탭(`target="_blank" rel="noopener"`).
- 못 읽은 칸은 `aria-invalid`를 붙이고, 그 안내를 결과용 낭독 줄(`#live`)로도 읽어 준다.
- 누르는 곳은 손가락으로 쓰는 화면(960px 이하·coarse)에서 44px 이상. 문장 속 링크는 뺀다. **최소 폭을 준 flex 항목은 글자보다 좁게 줄어들 수 있어 `flex:none`을 같이 준다**(메뉴에서 겪음. e2e의 SPILL이 본다).
- 휴대폰: 조건을 여는 동안 큰 숫자가 화면 밖이면 실수령액 한 줄을 화면 위에 붙여 둔다(`.stick`). 메뉴가 넘치면(320px) 지금 페이지가 보이게 밀어 두고 끝을 흐리게 한다. 바로 넣기 단추 넷은 한 줄(좁은 화면에서는 옆 여백을 줄인다).
- 영어판 420px 아래에서는 'Show the math' 단추를 '떼는 돈' 줄의 아랫줄로 내린다. 차액 꼬리표(`.chg-b`)는 금액 왼쪽이 기본이고, 항목 이름을 덮게 되면 금액 아래 빈 줄(`.under`), 그 자리도 없으면 진한 꼬리표(`.solid`) + 그 줄의 작은 설명·상태 꼬리표를 2초 숨김(`.tight`). app.js `clash()`가 글자 자리와 겹치는지 잰다.
- **칸에서 손을 뗄 때(blur) 명세서를 다시 그리지 않는다.** 다시 그리면 그 순간 누르던 명세서 안 단추(계산식 보기, 2027년 기준으로 보기)가 사라져 눌림이 씹힌다. `flush()`만 부른다.
- 연출 셋(app.js·style.css): 이중 밑줄 긋기(값을 넣고 0.6초 멈췄을 때, 결과가 바뀌었으면), 달라진 줄 짚기(기준 시기를 바꿨을 때 2초), 루멘랩 칸(화면에 들어올 때 한 번). 처음 열 때·되살릴 때·치는 중에는 움직이지 않는다. 동작 줄이기면 밑줄·루멘랩 칸은 멈춰 있고 차액 꼬리표만 보였다 사라진다.
- **글꼴**: Pretendard에서 이 사이트 화면에 나오는 글자와 굵기 400~800만 남긴 조각 하나(한국어판 약 83KB, 영어판 약 27KB. 이름은 'TK Sans': 'Pretendard'가 예약된 이름이라 바꿨다)를 **이 사이트에서** 받는다. `<head>`에서 preload하고 `font-display: optional`(늦게 와도 줄이 다시 짜이지 않는다). jsDelivr에는 접속하지 않는다. 조각에 없는 글자는 기기 글꼴로 보인다.
- 광고: 자동 광고 코드는 계산기·표·글 페이지 `<head>`에만(소개·방침·가이드 목록·404에는 없음). 수동 자리 `mid`·`bottom` 두 곳은 단위 번호가 비어 있어 지금은 화면에 없다. `?adpreview`나 localhost에서는 빗금 상자. 자리 폭은 글 기둥(780px).
- 표: 넓은 표(`.tbl.wide`)는 640px 아래에서 표 안에서 옆으로 밀고 '표를 옆으로 밀어 보세요'가 같이 나온다. 출처 표(`.tbl.rows`)는 좁은 화면에서 줄 카드, 출처 링크는 한 줄에 하나(`.srcs`). 연봉 표는 **줄 어디를 눌러도** 그 연봉으로 계산기가 열리고, 휴대폰에서 3칸으로 줄였다가 '항목별로 보기'를 누르면 전부 보이며 옆으로 밀어도 연봉 칸은 왼쪽에 붙어 있다(sticky).
- 저장: localStorage `tk.lang`(언어 안내 띠를 닫았거나 언어 링크를 눌렀다는 표시)과 sessionStorage `tk.in`(입력 유지) 둘뿐. 방침에 그대로 적었고 check.py가 app.js의 키와 대조한다.
- 방침: 방문 통계는 Cloudflare Web Analytics라고 적는다(페이지·직전 주소·브라우저 종류·성능 정보). "아무것도 보내지 않아요"·"저장하지 않아요"처럼 넓게 쓰지 않는다(check.py가 그런 문장을 찾는다).
- 404: 한 장이 두 언어를 다 보여 준다. 제목은 두 언어이고, 주소가 `/en/` 아래면 인라인 스크립트가 제목·`lang`·머리 링크를 영어로 맞춘다.
- lastmod: build.py `UPDATED`에 본문·구조화 데이터·링크가 바뀐 페이지만 적는다. 글의 '마지막 확인' 날짜도 같은 값이다.

## 주의할 점
- 확인하지 못한 것은 화면·글에 쓰지 않는다: 외국인 단일세율, 구직급여 수급 제한 사유·피보험 단위기간 세는 법, 2027년 미정 값(구직급여 상한 포함), 최저임금 산입 범위, 연말정산 조문, 임의계속가입자의 보험료 부담. check.py가 낱말을 본다. 영어판에는 "This calculator uses the standard monthly withholding table that applies to residents"라는 범위 안내만 있다.
- **id는 쪽 안에서 하나씩**(같은 id가 둘이면 `#` 링크가 앞의 것으로 간다. 홈의 '계산 기준과 출처' 링크가 그렇게 어긋났었다). check.py가 겹침과 '`#basis`는 계산 기준 구역, `#main`은 본문'을 본다. 새 `#` 목적지를 만들면 check.py `PLACES`에 적는다.
- 시험의 기준값은 로직과 다른 데서 온다: 공단·고용노동부·법령 원문의 예시와 표, 고용노동부 화면에 직접 넣어 받은 값, 평가자의 대조 자료, 따로 옮겨 적은 간이세액표 표본 17줄, 파이썬 `calendar`·`Fraction`으로 낸 값, 손으로 따진 경계 사례. 로직을 고치면 `mutate.mjs`의 바꿈 목록도 같이 본다('못 찾음'이 나오면 목록을 고친다).
- `tests/gani_formula_check.py`가 쓰는 값 가운데 [역산]으로 표시한 것은 표에서 거꾸로 찾아낸 값이다. 법 조문으로 확인한 사실이 아니므로 화면·글에 쓰지 않는다.
- 영어 페이지에는 `lang="ko"` 밖 한글이 없어야 한다(check.py는 정적 HTML, e2e.py는 조건을 바꾼 뒤의 화면까지 본다). 영어 제도 이름과 출처 이름은 공식 영문 표기가 아니라 뜻을 풀어 쓴 것이다.
- 좁은 화면의 가로 넘침은 **휴대폰 흉내 없이 창 폭만 줄여서도** 잰다(흉내를 켜면 넘친 만큼 화면이 넓어져 안 잡힌다). e2e 묶음 1이 320·360·375px로 본다.
- 스크린샷을 Pretendard로 찍으려면 e2e.py처럼 첫 HTML 안 `@font-face`의 표시 방식을 swap으로 바꿔 줘야 한다(optional은 글꼴이 조금만 늦어도 기기 글꼴로 그린다).
- 광고 코드가 있는 실제 주소(`*.lumenlab.page`)는 자동 도구로 열지 않는다. 로컬에서도 광고 요청은 정규식으로 막는다(`googlesyndication|doubleclick|adservice|fundingchoices`).
