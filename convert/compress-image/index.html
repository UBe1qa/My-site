Compress Images (JPG and WebP)

4MB→600K

Shrink photos for forms, email or the web and watch the size change as you move the slider, all on your device.

or drop them here

Accepts: JPG, PNG, WebP

Converted on this device. Your files are never uploaded.

Limiting the width cuts size faster than the quality slider

File size follows pixel count. A 12-megapixel photo (4032 × 3024) has about 12.2 million pixels; capping the width at 1600 px (1600 × 1200) leaves 1.92 million, less than a sixth.

If the image will be viewed on a phone or a web page, set a max width first and use the slider for the last few kilobytes.

Lower quality removes fine detail first

Turning quality down blurs fine texture and can add blocky artifacts around edges and text. Watch the live size and the preview together and stop where it still looks right.

Quality numbers aren't comparable between apps: 80 in one program doesn't mean the same as 80 in another.

PNG files are converted, not optimized

This tool doesn't do lossless PNG optimization. A PNG is saved as JPG or WebP, which saves a lot for photos but can soften text in screenshots.

JPG can't store transparency and would turn transparent areas white, so PNGs with transparency default to WebP, which keeps it.

Questions

What if compressing makes a file bigger?

It shouldn't. If a compressed image would be bigger than the original, which can happen when the original was already heavily compressed, the original is kept and marked as such.

Is location data removed?

Yes. Re-encoding in the browser doesn't carry over EXIF data such as GPS location, camera model or capture time.

A site wants images under 500 KB. How do I hit that?

Set a max width such as 1600 px, then lower the quality until the live size drops below 500 KB.
