Merge PDF Files

PDF→1PDF

Combine several PDFs into a single file, merged locally on your device.

or drop them here

Accepts: PDF

Converted on this device. Your files are never uploaded.

Pages are copied, not re-printed

Merging copies each page's content into the new file, so text stays selectable and nothing is re-rendered or recompressed. The result is roughly the combined size of the inputs.

Bookmarks and some form fields may not survive

The outline (bookmarks panel) and some form fields may not carry over. If a document has fields you still need, fill them in and save it before merging.

PDFs that only restrict copying or printing can be merged. A PDF that needs a password to open has to be unlocked with Unlock PDF first.

Need only some pages? Split first

Set the order with the ↑ and ↓ buttons before merging. To include only part of a document, extract those pages with Split PDF, then merge the pieces.

Questions

Will the merged PDF be smaller?

No. Merging doesn't compress anything. If the merged file is too big, run it through Compress PDF afterwards.

Can I merge Word files or images?

Word files aren't supported. Images can be turned into a PDF with JPG to PDF and then merged here.

How many PDFs can I merge?

There's no fixed limit; very large files can run out of memory, especially on phones.
