Turn a PDF into Markdown before giving it to Claude

Updated 2026-10-07 · Lumen Lab

When you attach a PDF to Claude, every page is used twice: Claude reads the extracted text, and it also looks at an image of the page so it can follow charts and layout. If the PDF is mostly words, you can skip the second part by converting it to Markdown first and pasting the text instead. The page images are gone, so the request uses fewer tokens. If the meaning is in the pictures, keep the PDF.

How Claude reads a PDF

Anthropic’s documentation describes the cost in two parts. Text typically uses 1,500 to 3,000 tokens per page, depending on how dense the page is. On top of that, each page is converted into an image, and that image is charged like any other image: one token per 28×28-pixel patch, after the image is shrunk to fit the model’s limit.

That limit is what caps the image part. Working the documented formula through for one page:

One page as an imageMost Claude modelsClaude 4.7 and later
Limit (long edge, tokens)1,568 px, 1,568 tokens2,576 px, 4,784 tokens
A4 page, at mostabout 1,551 tokensabout 4,756 tokens
US Letter page, at mostabout 1,496 tokensabout 4,758 tokens

These are calculated ceilings, not measurements: the documentation doesn’t say at what size a PDF page is rendered. Anthropic does give one measured example, for Amazon Bedrock’s Converse API: a 3-page PDF used about 1,000 tokens with text extraction only and about 7,000 tokens with full visual understanding.

What we measured

We ran three public or self-made PDFs through PDF to Markdown with the default settings and counted what came out. We didn’t send them to Claude, so there are no measured token counts here; the last column is the page-image ceiling from the table above, which is what converting removes at most.

PDFPages · sizeMarkdownPage images removed, at most
Research paper, two columns (Attention Is All You Need)15 · 2.2 MB39,939 characters (40 KB), 6 tablesabout 23,000 tokens, or 71,000 on Claude 4.7+
Tax form (IRS Form W-4, 2026)5 · 209 KB27,942 characters (28 KB), 12 tablesabout 7,500 tokens, or 24,000 on Claude 4.7+
Korean guide saved as PDF3 · 123 KB3,179 characters (5.7 KB), 4 tablesabout 4,700 tokens, or 14,000 on Claude 4.7+

The paper’s Markdown is under 2% of the PDF’s file size, but file size isn’t what Claude charges for; the point of the table is that the text is all there in a much smaller package. A page with little text saves the most in proportion, because its image costs the same as a full page.

When converting helps

  • Text-heavy documents: reports, contracts, terms, papers, manuals, meeting notes.
  • Long documents: the more pages, the more page images you avoid. On claude.ai, PDFs of 100 pages or fewer are analyzed with their visuals; longer ones (up to 1,000 pages) are already read as text only.
  • Repeated questions: in a long chat the document is part of every turn, so a smaller version keeps the conversation lighter.

When to keep the PDF

  • Charts, graphs and diagrams carry information the text doesn’t. Converting drops them.
  • Scans and photos of pages have no text layer, so there is nothing to convert. The tool tells you which pages came out empty.
  • Layout-heavy pages such as forms with checkboxes, slides, or tables with merged cells can come out shifted. Check the preview before you rely on a table.

How to do it

  1. Open PDF to Markdown and drop in the PDF. It is read on your device; nothing is uploaded.
  2. Leave the page markers on if you want to ask about specific pages, and leave repeated headers and footers removed.
  3. Press Convert to Markdown, read the preview, then Copy text or download the .md file.
  4. Paste it into Claude (or attach the .md file) and ask your question. If one chart matters, attach just that page as an image alongside the text.

On the command line: MarkItDown

Microsoft’s free, open-source MarkItDown does the same job from a terminal and also handles Word, PowerPoint and Excel files. With Python installed, pip install 'markitdown[all]' installs it and markitdown report.pdf -o report.md converts a file. It is a good fit for converting many files at once; the page here needs no install and keeps headings, lists and tables from the page layout.
