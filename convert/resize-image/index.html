Resize Images by Pixels or Percent

4000→1200

Change image dimensions for a form, profile or web page, resized locally in your browser.

or drop them here

Accepts: JPG, PNG, WebP

Converted on this device. Your files are never uploaded.

Keep the ratio locked to avoid stretching

With the lock on, changing the width recalculates the height: a 4000 × 3000 photo set to 1200 px wide becomes 1200 × 900.

With the lock off you can type both values, but the picture is stretched or squashed unless the new ratio matches the old one.

Shrinking is safe; enlarging adds no detail

Scaling down discards pixels and usually looks sharp. Scaling up, say to 200%, fills in new pixels by interpolation, so the image gets bigger but softer, not more detailed.

You're setting pixels, not print size

Print size depends on the resolution you print at: 1200 px printed at 300 DPI is 4 inches (about 10 cm) wide.

Files keep their format where possible: JPG stays JPG, PNG stays PNG with its transparency, and WebP stays WebP.

Questions

Does resizing reduce the file size?

Yes. Fewer pixels means a smaller file. If you need a specific size in KB, use Compress image.

Can I resize many images to the same width?

Yes. Add them all, set the size once, and download them individually or as a ZIP.

Can I crop to a square?

No, this tool only scales. Cropping needs another app.
