Why nothing gets uploaded

Most online converters send your file to their server, convert it there and send it back. Inplace does the work inside this browser tab instead, using features every modern browser already has (WebCodecs for audio and video, canvas for images) plus open-source libraries for PDF and spreadsheets.

That means your file never leaves your device: there is no upload to wait for, no copy on someone else's computer, and no file size limit set by a server. The only limit is your device's memory, so very long videos work best on a computer.
