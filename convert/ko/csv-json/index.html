CSV→JSON

CSV와 JSON을 미리보기로 확인하면서 바꿔요. 데이터는 브라우저 밖으로 나가지 않아요.

또는 여기에 끌어 놓기

받는 형식: CSV, TSV, JSON

이 기기 안에서 변환해요. 파일이 어디에도 올라가지 않아요.

엑셀에서 열 CSV라면 BOM을 켜세요

엑셀은 파일 맨 앞에 BOM(바이트 순서 표시, EF BB BF 세 바이트)이 있을 때만 UTF-8로 알아봐요. BOM이 없으면 한국어 윈도우의 기본 코드 페이지(949)로 읽어서 한글이 '�븞�뀞'처럼 깨져 보여요.

그래서 '엑셀에서 한글 안 깨지게 (UTF-8 BOM)' 옵션이 처음부터 켜져 있어요. 프로그램에서 읽을 파일이라면 꺼 주세요.

CSV → JSON: 키와 자료형을 정하세요

'첫 줄을 키로'를 켜면 각 줄이 {"이름": "김민지", "나이": "34"} 같은 객체가 되고, 끄면 값만 담긴 배열이 돼요. 구분자(쉼표, 세미콜론, 탭)는 자동으로 찾아요.

CSV에는 자료형이 없어서 '숫자와 true/false를 값으로'를 켜지 않으면 모든 값이 문자열로 남아요. 켜면 열마다 판단해요. 빈칸을 뺀 모든 값이 앞자리 0 없는 평범한 숫자인 열만 숫자가 되고, 아니면 그 열 전체가 글자로 남아요. 그래서 우편번호 열에 01234와 12345가 섞여 있으면 둘 다 글자 그대로예요.

JSON → CSV: 중첩된 값은 글자로 들어가요

객체가 담긴 배열을 넣으면 돼요. 머리글은 모든 객체의 키를 합친 것이라, 어떤 객체에 없는 키는 빈칸이 돼요.

객체 안의 객체나 배열은 ["a","b"]처럼 JSON 글자 그대로 한 칸에 들어가요.

자주 묻는 질문

BOM은 항상 켜는 게 좋나요?

아니요. BOM을 예상하지 않는 프로그램은 첫 머리글 앞에 이상한 글자가 붙은 것처럼 읽어요. 엑셀용으로 처음엔 켜져 있지만, 개발용이면 끄세요.

이미 받은 CSV가 엑셀에서 깨져요.

엑셀의 데이터 › 텍스트/CSV에서 메뉴로 가져오면서 파일 원본을 65001(UTF-8)로 고르면 제대로 보여요. 아니면 여기서 BOM을 붙여 다시 저장해도 돼요.

용량 제한이 있나요?

기기 메모리만큼이에요. 아주 큰 파일은 미리보기가 느릴 수 있지만 데이터는 브라우저 밖으로 나가지 않아요.
