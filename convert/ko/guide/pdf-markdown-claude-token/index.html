PDF를 마크다운으로 바꿔서 클로드에 넣기

고친 날 2026-10-07 · Lumen Lab

클로드에 PDF를 넣으면 쪽마다 두 번 쓰여요. 뽑아낸 글자를 읽고, 그래프와 배치를 보려고 쪽을 그림으로도 봐요. 글 위주의 PDF라면 먼저 마크다운으로 바꿔 글만 붙여 넣으면 이 그림 몫이 빠져서 토큰이 줄어요. 반대로 뜻이 그림에 있는 PDF는 그대로 넣는 게 맞아요.

클로드는 PDF를 이렇게 읽어요

앤트로픽 문서는 비용을 두 부분으로 설명해요. 글은 쪽의 빽빽한 정도에 따라 보통 쪽마다 1,500~3,000토큰이에요. 여기에 쪽마다 그림으로 바꾼 몫이 더해지는데, 다른 그림과 똑같이 모델 한도에 맞게 줄인 뒤 28×28픽셀 조각 하나에 1토큰씩 세요.

그림 몫의 최대치는 이 한도가 정해요. 문서의 계산식을 한 쪽에 대입하면 이래요.

쪽 하나를 그림으로 볼 때대부분의 클로드 모델클로드 4.7 이후 모델
한도 (긴 변, 토큰)1,568px, 1,568토큰2,576px, 4,784토큰
A4 한 쪽, 최대약 1,551토큰약 4,756토큰

이건 계산한 최대치이고 잰 값이 아니에요. 문서에는 PDF 쪽을 어떤 크기로 그리는지 나와 있지 않거든요. 대신 앤트로픽이 직접 든 예가 하나 있어요. 아마존 베드록의 Converse API에서 3쪽짜리 PDF가 글만 뽑아 읽으면 약 1,000토큰, 그림까지 보면 약 7,000토큰이었어요.

직접 재 본 결과

공개된 PDF와 직접 만든 PDF 세 개를 PDF 마크다운 변환에 기본 설정으로 넣고 나온 결과를 셌어요. 클로드에 보내 보지는 않아서 실제 토큰 수는 없어요. 마지막 칸은 위 표의 쪽 그림 최대치로, 바꾸면 최대 이만큼이 빠진다는 뜻이에요.

PDF쪽 · 용량마크다운빠지는 쪽 그림 (최대)
두 단 논문 (Attention Is All You Need)15쪽 · 2.2MB39,939자 (40KB), 표 6개약 23,000토큰, 클로드 4.7 이후는 약 71,000
미국 세금 서식 (W-4, 2026)5쪽 · 209KB27,942자 (28KB), 표 12개약 7,500토큰, 클로드 4.7 이후는 약 24,000
한국어 가이드 글을 PDF로 저장한 것3쪽 · 123KB3,179자 (5.7KB), 표 4개약 4,700토큰, 클로드 4.7 이후는 약 14,000

논문의 마크다운은 PDF 파일 용량의 2%도 안 되지만, 클로드는 파일 용량으로 토큰을 세지 않아요. 이 표에서 볼 건 글은 그대로 다 들어 있다는 점이에요. 글이 적은 쪽일수록 그림 몫은 똑같아서 줄어드는 비율이 커요.

바꾸면 좋은 경우

  • 글 위주 문서: 보고서, 계약서, 약관, 논문, 설명서, 회의록.
  • 긴 문서: 쪽이 많을수록 빠지는 그림도 많아요. 참고로 claude.ai에서는 100쪽 이하 PDF만 그림까지 분석하고, 101~1,000쪽은 원래 글만 읽어요.
  • 여러 번 물어볼 때: 대화가 길어지면 문서가 매번 다시 들어가니, 가벼운 쪽이 대화도 가벼워요.

PDF 그대로 넣는 게 나은 경우

  • 그래프·도표·도식에 글에 없는 정보가 있으면 바꾸면 사라져요.
  • 스캔본·종이를 찍은 PDF는 글자 층이 없어 바꿀 글이 없어요. 어느 쪽이 비었는지 도구가 알려 줘요.
  • 배치가 중요한 쪽(체크 칸이 있는 서식, 발표 자료, 칸을 합친 표)은 어긋날 수 있어요. 표가 중요하면 미리 보기에서 확인하세요.

이렇게 하면 돼요

  1. PDF 마크다운 변환을 열고 PDF를 넣어요. 내 기기 안에서 읽고 어디에도 올라가지 않아요.
  2. 몇 쪽 내용인지 물어볼 거라면 '쪽이 시작하는 곳 표시하기'를 켜 두고, 머리말·꼬리말 빼기도 켜 둬요.
  3. 마크다운으로 바꾸기를 누르고 미리 보기를 본 뒤 글 복사하기나 .md 파일 받기를 눌러요.
  4. 클로드에 붙여 넣거나 .md 파일을 올리고 물어보면 돼요. 그래프 하나가 꼭 필요하면 그 쪽만 그림으로 같이 올려요.

명령줄로 하려면: MarkItDown

마이크로소프트의 무료 오픈소스 MarkItDown은 같은 일을 터미널에서 하고, 워드·파워포인트·엑셀 파일도 바꿔요. 파이썬이 있으면 pip install 'markitdown[all]'로 깔고 markitdown 보고서.pdf -o 보고서.md로 바꿔요. 파일을 한꺼번에 많이 바꿀 때 좋고, 이 페이지는 설치 없이 쪽 모양을 보고 제목·목록·표를 살려요.
