CSV keeps values, not the workbook

A CSV file is plain text: one sheet, with no formatting, formulas or charts. Exporting writes each cell's last calculated value, so a cell containing =SUM(A1:A3) becomes its result.

Because a CSV holds only one sheet, choose a sheet, or export every sheet as its own CSV inside a ZIP.

Dates come out as the text you see

Excel stores dates as serial numbers counting days from January 1, 1900; October 6, 2026 is 46301. This converter writes dates as their displayed text instead, so they don't turn into bare numbers in the CSV.

The text follows each cell's display format, so check that it matches what the receiving system expects.

CSV to XLSX gives you a real workbook

Converting a CSV to XLSX lets you add formatting, formulas and more sheets in Excel. One worksheet holds at most 1,048,576 rows and 16,384 columns.

A column where every value is a plain number with no leading zero is saved as real numbers, so you can sum it. Columns such as ZIP codes or phone numbers with leading zeros stay text, so the zeros aren't lost.

Questions

Are formulas kept?

No. CSV can't store formulas; only each cell's last calculated value is written.

Can I open old .xls or LibreOffice .ods files?

Yes. XLS (Excel 97–2003) and ODS files can be exported to CSV just like XLSX.

The CSV shows garbled characters in Excel. What now?

Turn on “Excel-friendly (UTF-8 with BOM)” on this page before converting, so Excel reads the file as UTF-8. For a CSV you already have, import it with Data › From Text/CSV and set File Origin to 65001: Unicode (UTF-8).
