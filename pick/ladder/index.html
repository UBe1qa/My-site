    How to use it

    Names from your list sit along the top. Type what goes along the bottom, one item per line, for example Winner or a chore. If you give fewer items than people, the rest are left blank. Press Make ladder, then tap a name to follow that person’s path down, or press Show all results.

    Why the bottom row is shuffled

    A plain ladder is not as random as it looks. With the usual number of rungs, a person tends to end up close to where they started. In our own runs with 8 people and a medium ladder, the person on the far left landed directly below their start 24.8% of the time, when a fair draw would give 12.5%.

    So this tool shuffles the bottom row first and then builds the ladder. With that step every person is equally likely to get every result, however few rungs there are. The guide has the numbers.

    What the ladder guarantees

    Every ladder gives each person exactly one result and each result to exactly one person. Two rungs never meet the same upright at the same height, so each path is unambiguous. These rules are checked by automated tests on thousands of generated ladders.

    Questions

    Why is the limit 30 people?

    Beyond 30 uprights the ladder is too narrow to follow on a screen. For bigger groups, the name picker draws winners or an order from a list of any length.

    Can other people check the result later?

    Yes. Copy result link stores the names, the bottom row and the seed in the address. Opening it rebuilds the same ladder with the same results.
