Ladder game

Also called Ghost Leg or Amidakuji. For 2 to 30 people.

Set the bottom row (prizes, chores) and the rungs
Rungs

Press Make ladder. The rungs stay hidden until someone goes down.

The link holds the names in their order and the bottom row. For a ladder, a different order of names or of bottom-row items means a different result.Check code: 8 names · a2cd208d

How does it pick? Each press uses fresh random numbers from your browser. Your list is not sent to a server; it only travels inside a result link if you make one and send it.

Details

Each press asks your browser for a new 32-byte value, the seed, with crypto.getRandomValues(). A fixed calculation called xoshiro256** then turns that seed into the numbers the pick needs. That is why the same seed and the same names give the same result on anyone’s device. See exactly how picks are made

The ladder check code under the list is a short summary of the names in their order plus the bottom row. Post it before you draw, and anyone who opens the result link can compare codes to see that the order and the bottom row are unchanged.

    How to use it

    Names from your list sit along the top. Type what goes along the bottom, one item per line, for example Winner or a chore. If you give fewer items than people, the rest are left blank. If you give more, only as many as there are people are used and a note says how many were left out. Press Make ladder, then tap a name to follow that person’s path down, or press Show all results.

    Why the bottom row is shuffled

    A plain ladder is not as random as it looks. With the usual number of rungs, a person tends to end up close to where they started. In our own runs with 8 people and a medium ladder, the person on the far left landed directly below their start 24.8% of the time, when a fair draw would give 12.5%.

    So this tool shuffles the bottom row first and then builds the ladder. With that step every person is equally likely to get every result, however few rungs there are. The guide has the numbers.

    What the ladder guarantees

    Every ladder gives each person exactly one result and each result to exactly one person. Two rungs never meet the same upright on the same level, so each path is unambiguous. These rules are checked by automated tests on thousands of generated ladders.

    Questions

    Why is the limit 30 people?

    Beyond 30 uprights the ladder is too narrow to follow on a screen. For bigger groups, the name picker draws winners or an order from a list of up to 5,000 names.

    Can other people check the result later?

    Yes. Copy result link stores the names in their order, the bottom row and the value the ladder was built from (the seed) in the address. Opening it rebuilds the same ladder with the same results. In a ladder, who stands on which line and the order of the bottom-row items are part of the result, so both orders have to be the same as well. The ladder check code under the list covers both, so if you post it beforehand people only need to compare codes.
