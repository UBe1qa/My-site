Spin the Wheel

One list for the wheel, the ladder and the name picker. Every result can be rechecked from a link.

How does it pick? Each press uses fresh random numbers from your browser. Your list is not sent to a server; it only travels inside a result link if you make one and send it.

Details

Each press asks your browser for a new 32-byte value, the seed, with crypto.getRandomValues(). A fixed calculation called xoshiro256** then turns that seed into the numbers the pick needs. That is why the same seed and the same names give the same result on anyone’s device. See exactly how picks are made

The check code under the list is a short summary of the list. The same people always give the same code. Post it with the list before you draw, and anyone who opens the result link can compare codes to see that the list is the same.

      How to use it

      Type one name per line in the list, or paste a whole column from a spreadsheet. If you type a single line, it is split at the commas. Press Spin in the middle of the wheel and the name under the pointer appears in large type.

      Remove and spin again takes the name that was just picked off the wheel only, and spins straight away. The text in your list and the saved list stay as they were. The people taken off are shown under the list, and Bring everyone back puts them on the wheel again. If you enter a name twice it gets two slots and twice the chance. That is the only kind of weighting here, and it is always visible on the wheel.

      How many entries can it take?

      The list accepts up to 5,000 lines, and each name up to 100 characters. Anything beyond that is left out, and a note under the list says how much. The wheel has been checked to spin smoothly with 500 slots. When there are too many slots to read the names, the result still appears in large type and the winning slot is widened so that its name shows on the wheel.

      How the pick is made

      Each spin asks your browser for a fresh value, the seed, with crypto.getRandomValues(). The winner is decided from that seed first, and then the wheel is turned so that it stops on that slot. The result is never read from where the wheel happened to stop. The spin runs to the end with the list as it was when you pressed Spin, and the list is locked while the wheel turns. So the highlighted slot, the name in large type and the result link always point to the same person. There is no setting that makes a chosen name come up.

      The result link

      Copy result link builds an address that holds the names on the wheel and the seed. Anyone who opens it gets the same winner recalculated. The pick works from the names placed in a fixed order (sorted by character code), so changing only the order of the names inside a link cannot make someone else the winner. Invisible characters in names, such as zero-width spaces, are removed when a list is read, and a link that contained them is flagged. The check code under the result is a short summary of the list: if it matches the code posted before the draw, the list is the same. The list sits after the # in the address, so it is not sent to a server, but whoever gets the link can read the list. A link cannot show whether someone spun several times and sent only the result they liked.

      Questions

      Can I make a certain name win?

      No. That feature does not exist here. The only way to change the odds is one everybody can see, such as entering a name more than once.

      Is my list uploaded anywhere?

      No. The list is not sent to a server and is saved in this browser only. It travels inside a result link only if you make one and send it. Clear list removes the saved list, and the Clear results too button that follows removes the recent results, whose links contain the list. The privacy policy explains how ads and visit statistics work.

      Can I use it as a yes or no wheel?

      Yes. Put Yes and No on two lines and spin. Any short list works the same way, such as lunch options or numbers.
