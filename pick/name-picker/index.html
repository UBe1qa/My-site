    Three ways to draw

    Pick names draws as many names as you ask for, in the order they came out, and never the same line twice. Slips gives everyone a folded slip, with as many winning slips as you set; tap a slip to open it. Order puts the whole list in a random sequence, for presentations or turns.

    How the draw is made

    All three use the same shuffle, Fisher–Yates, driven by a seed made from your browser’s cryptographic random numbers. Every possible order is equally likely. Automated tests draw 100,000 times with fixed seeds and check that no name comes up more often than chance allows.

    Duplicate lines

    No repeats means no line is drawn twice. If the same name is on two lines, it counts as two entries and both can be drawn. Use Remove duplicates above the list if you want one entry per name.

    Questions

    How many names can the list hold?

    Up to 5,000 lines. You can paste them in one go.

    Can I prove the draw to others?

    Copy result link stores the list and the seed, and opening it replays the same result. It shows the result was not changed afterwards. It cannot show how many times you drew before sharing, so agree on a single draw in advance or draw where everyone can watch.
