How does it pick? Each press uses fresh random numbers from your browser. Your list is not sent to a server; it only travels inside a result link if you make one and send it.

Details

Each press asks your browser for a new 32-byte value, the seed, with crypto.getRandomValues(). A fixed calculation called xoshiro256** then turns that seed into the numbers the pick needs. That is why the same seed and the same names give the same result on anyone’s device. See exactly how picks are made

The check code under the list is a short summary of the list. The same people always give the same code. Post it with the list before you draw, and anyone who opens the result link can compare codes to see that the list is the same.

    Three ways to draw

    Pick names draws as many names as you ask for, in the order they came out, and never the same line twice. Slips gives everyone a folded slip, with as many winning slips as you set; tap a slip to open it. Order puts the whole list in a random sequence, for presentations or turns.

    How the draw is made

    All three use the same shuffle, Fisher–Yates. Each press takes a fresh value from your browser, the seed, and shuffles with it. Every possible order is equally likely. The draw works from the names placed in a fixed order (sorted by character code), so however you typed the list, the same seed and the same people give the same winners. Names are compared as they look: invisible characters such as zero-width spaces are removed when the list is read. Automated tests draw 100,000 times with fixed seeds and check that no name comes up more often than chance allows.

    Duplicate lines

    No repeats means no line is drawn twice. If the same name is on two lines, it counts as two entries and both can be drawn. Use Remove duplicates under the list if you want one entry per name.

    Questions

    How many names can the list hold?

    Up to 5,000 lines. You can paste them in one go.

    Can I prove the draw to others?

    Copy result link stores the list and the value the draw was made from (the seed), so anyone who opens it gets the same result recalculated. With the same seed and the same people, the result is the same even if the list is in a different order. There are things a link cannot show: whether you drew several times and sent only the link you liked, or whether someone was added to or left off the list before the draw. So post the list and the check code shown under it before you draw, and agree on a single draw or draw where everyone can watch. Whoever opens the link can then compare the check code under the result with the one you posted.
