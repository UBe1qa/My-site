PDF를 마크다운으로 바꿔서 AI에 넣기

루멘랩 · 마지막 확인 2026. 10. 7.

인플레이스이미지·영상·PDF 파일 변환열기 ↗

AI 채팅이나 에이전트에 PDF를 넣으면, 많은 서비스가 쪽마다 두 번 써요. 뽑아낸 글자를 읽고, 그래프와 배치를 보려고 쪽을 그림으로도 봐요. 글 위주의 PDF라면 먼저 마크다운으로 바꿔 글만 붙여 넣으면 이 그림 몫을 건너뛸 수 있어요. ChatGPT든 클로드든 제미나이든 마찬가지예요. 마크다운은 그냥 글자 파일이라 어떤 AI든 읽을 수 있어요. 다만 토큰이 얼마나 줄지는 서비스가 PDF를 세는 방식에 달려 있고, 안 주는 곳도 있어요.

AI 서비스는 PDF를 이렇게 세요

세 회사가 API에서 PDF를 어떻게 다루는지 공개하고 있어요. 그 위에 만든 채팅 앱은 다르게 동작할 수 있고, 대부분 공개하지 않아요.

API쪽 하나가 바뀌는 것쪽당 비용
OpenAI (GPT-4o 이후)뽑은 글 + 쪽 그림숫자는 없고, 쪽 그림 때문에 "토큰 사용량이 늘 수 있다"고 안내
앤트로픽 클로드뽑은 글 + 쪽 그림글 약 1,500~3,000토큰 + 그림 (그림 계산식으로 A4 한 쪽 최대 약 1,551토큰, 클로드 4.7 이후 약 4,756토큰)
구글 제미나이쪽을 그림처럼 읽음, 제미나이 3은 PDF 속 글자를 요금에 넣지 않음제미나이 3: 기본 약 560토큰 (낮은 해상도 280, 높은 해상도 1,120). 이전 모델: 258토큰

그래서 글과 쪽 그림을 둘 다 세는 곳에서 효과가 커요. 앤트로픽이 직접 든 예로는 아마존 베드록에서 3쪽짜리 PDF가 글만 뽑아 읽으면 약 1,000토큰, 그림까지 보면 약 7,000토큰이었어요. 반대로 제미나이 API에서는 쪽당 258~560토큰 정도라, 글이 빽빽한 쪽을 붙여 넣으면 그보다 더 들 수 있어요.

직접 재 본 결과

공개된 PDF와 직접 만든 PDF 네 개를 PDF 마크다운 변환에 기본 설정으로 넣고 나온 결과를 셌어요. AI에 보내 보지는 않아서 실제 토큰 수는 없어요. 마지막 칸은 계산식을 공개한 유일한 곳인 앤트로픽의 그림 계산식으로, 거기서 쪽 그림이 최대 얼마였을지를 적었어요.

PDF쪽 · 용량마크다운클로드 쪽 그림 (최대)
한 단 논문 (Attention Is All You Need)15쪽 · 2.2MB39,909자 (40KB), 표 6개약 22,000토큰, 클로드 4.7 이후는 약 71,000
두 단 논문 (ResNet, Deep Residual Learning)12쪽 · 819KB62,294자 (63KB)약 18,000토큰, 클로드 4.7 이후는 약 57,000
미국 세금 서식 (W-4, 2026)5쪽 · 209KB27,926자 (28KB), 표 12개약 7,500토큰, 클로드 4.7 이후는 약 24,000
한국어 가이드 글을 PDF로 저장한 것3쪽 · 123KB3,179자 (5.7KB), 표 4개약 4,700토큰, 클로드 4.7 이후는 약 14,000

논문의 마크다운은 PDF 파일 용량의 2%도 안 되지만, 파일 용량으로 토큰을 세는 AI는 없어요. 이 표에서 볼 건 글은 그대로 다 들어 있다는 점이에요. 쪽 그림을 세는 곳에서는 글이 적은 쪽일수록 그림 몫이 똑같아서 줄어드는 비율이 커요.

바꾸면 좋은 경우

  • 글 위주 문서: 보고서, 계약서, 약관, 논문, 설명서, 회의록.
  • 긴 문서: 쪽이 많을수록 빠지는 그림도 많아요. 긴 파일은 이미 글만 읽는 앱도 있어요. 예를 들어 claude.ai는 100쪽 이하 PDF만 그림까지 분석해요.
  • 긴 대화·에이전트: 문서가 매번 다시 들어가니, 가벼운 쪽이 요청마다 가벼워요.
  • PDF를 못 받는 도구: 글자는 어디든 들어가요. 내 컴퓨터에서 돌리는 모델이나 오래된 API도요.

PDF 그대로 넣는 게 나은 경우

  • 그래프·도표·도식에 글에 없는 정보가 있으면 바꾸면 사라져요.
  • 스캔본·종이를 찍은 PDF는 글자 층이 없어 바꿀 글이 없어요. 어느 쪽이 비었는지 도구가 알려 줘요.
  • 배치가 중요한 쪽(체크 칸이 있는 서식, 발표 자료, 칸을 합친 표)은 어긋날 수 있어요. 표가 중요하면 미리 보기에서 확인하세요.
  • PDF 쪽을 정해진 값으로 세는 서비스(제미나이 3 API 등)는 PDF가 이미 더 쌀 수 있어요.

이렇게 하면 돼요

  1. PDF 마크다운 변환을 열고 PDF를 넣어요. 내 기기 안에서 읽고 어디에도 올라가지 않아요.
  2. 몇 쪽 내용인지 물어볼 거라면 '쪽이 시작하는 곳 표시하기'를 켜 두고, 머리말·꼬리말 빼기도 켜 둬요.
  3. 마크다운으로 바꾸기를 누르고 미리 보기를 본 뒤 글 복사하기나 .md 파일 받기를 눌러요.
  4. AI 채팅에 붙여 넣거나 .md 파일을 올리고 물어보면 돼요. 그래프 하나가 꼭 필요하면 그 쪽만 그림으로 같이 올려요.

명령줄로 하려면: MarkItDown

마이크로소프트의 무료 오픈소스 MarkItDown은 같은 일을 터미널에서 하고, 워드·파워포인트·엑셀 파일도 바꿔요. 파이썬이 있으면 pip install 'markitdown[all]'로 깔고 markitdown 보고서.pdf -o 보고서.md로 바꿔요. 파일을 한꺼번에 많이 바꿀 때 좋고, 이 페이지는 설치 없이 쪽 모양을 보고 제목·목록·표를 살려요.

출처

  • OpenAI API 문서: PDF 파일 입력 (글과 쪽 그림)
  • Claude 문서: PDF 지원 (쪽마다 글·그림 비용, 베드록 예)
  • Claude 문서: 비전 (그림 토큰 계산식과 크기 한도)
  • 제미나이 API 문서: 문서 이해 (쪽당 258토큰, 제미나이 3은 PDF 속 글자 요금 없음)
  • 제미나이 API 문서: 미디어 해상도 (제미나이 3의 PDF 쪽당 토큰)
  • Claude 고객센터: 파일 올리기 (100쪽 그림 분석 한도)
  • 마이크로소프트 MarkItDown (GitHub)
  • Vaswani 외, Attention Is All You Need (arXiv 1706.03762), 시험 파일
  • He 외, Deep Residual Learning for Image Recognition (arXiv 1512.03385), 두 단 시험 파일
  • 미국 국세청 W-4 양식, 시험 파일

인플레이스 가이드 더 보기

  1. 아이폰 사진 HEIC를 JPG로 바꾸는 법아이폰 사진이 HEIC인 이유, JPG로 바꿔야 하는 경우, 설정 › 카메라 › 포맷 › 높은 호환성과 'Mac 또는 PC로 전송' 설정, 이미 찍은 사진을 변환하는 방법까지 정리했어요.
  2. CSV를 엑셀에서 열면 한글이 깨지는 이유와 해결법CSV를 엑셀에서 열면 한글이 깨지는 이유(BOM 없는 UTF-8을 코드 페이지 949로 읽음)와, UTF-8 BOM 저장·'텍스트/CSV에서' 가져오기로 해결하는 방법을 정리했어요.
  3. 유튜브 영상을 MP3로 바꿔도 될까요?유튜브 약관이 다운로드에 대해 정한 내용, 저작권법 제104조의2·제136조·제30조 조문, 프리미엄 오프라인 저장과 유튜브 스튜디오 다운로드 같은 합법적인 대안을 정리했어요.
  4. PDF 용량 줄이기: 스캔 PDF가 큰 이유와 줄이는 법제출 서류나 메일 첨부가 용량 제한에 걸릴 때 PDF를 줄이는 방법. 스캔 PDF가 큰 이유, 압축 단계 고르는 법, Gmail 25MB 제한, 압축으로 안 줄어드는 경우를 정리했어요.
  5. PDF 암호 해제하는 법: 암호를 알 때와 모를 때카드 명세서처럼 암호를 아는 PDF의 암호를 푸는 방법, 열기 암호와 권한 암호(인쇄·복사 제한)의 차이, 잊어버린 열기 암호는 왜 풀 수 없는지 정리했어요.
  6. 동영상 용량 줄이기: 메일로 보낼 수 있게 만드는 법동영상 용량을 정하는 해상도·비트레이트·길이, Gmail 25MB·Outlook 20MB 같은 첨부 한도, 자르고 압축하는 순서, 링크로 보내는 편이 나은 경우를 정리했어요.
  7. PDF 합치기: 기기별로 여러 PDF를 하나로 묶는 법맥 미리보기와 Finder의 PDF 생성, 아이폰 미리보기 앱의 파일에서 삽입, 윈도우·안드로이드에서 브라우저로 PDF를 합치는 방법과 합치기 전 쪽 정리·압축 요령을 정리했어요.
