PDF 암호 해제하는 법: 암호를 알 때와 모를 때

루멘랩 · 마지막 확인 2026. 10. 6.

인플레이스이미지·영상·PDF 파일 변환열기 ↗

메일로 받은 카드 이용대금 명세서, 급여명세서, 보험 서류 PDF는 열 때마다 암호를 넣어야 하는 경우가 있어요. 암호를 알고 있다면 암호를 푸는 건 금방이에요. 그 암호로 파일을 풀어서 암호 없이 열리는 사본을 저장하면 돼요. 반대로 열기 암호를 잊어버렸다면 지름길은 없어요. 암호가 곧 파일을 여는 열쇠이기 때문이에요. 이 글에서는 내가 가진 PDF가 어떤 암호인지 구분하는 법, PDF 암호 풀기로 푸는 순서, 풀 수 없는 경우를 차례로 정리했어요.

PDF 암호는 두 가지예요

  • 열기 암호(사용자 암호): 파일을 열 때부터 묻는 암호예요. 이 암호가 없으면 내용이 암호화된 채로 남아서 볼 수 없어요.
  • 권한 암호(소유자 암호): 파일은 그냥 열리지만 인쇄, 글자 복사, 편집 같은 기능이 막혀 있어요. 이 제한을 푸는 게 권한 암호예요.

PDF 도구 qpdf의 문서를 보면 두 암호의 관계를 알 수 있어요. 두 암호는 모두 같은 암호화 키를 꺼내는 데 쓰여서, 어느 쪽 암호로도 키를 얻을 수 있어요. 또 사용자 암호를 빈칸으로 두고 암호화할 수도 있는데, 이 경우 빈 문자열로 키가 풀리니 암호 없이 열리고 제한만 남아요. qpdf 문서는 이런 파일을 '암호화는 됐지만 암호로 보호되지는 않은 파일'이라고 설명해요. 흔히 '인쇄가 안 되는 PDF'라고 부르는 파일이 대부분 이 경우예요.

내 PDF는 어떤 경우일까요

열어 보면뜻풀 때 필요한 것
내용이 보이기 전에 암호부터 물어요열기 암호그 암호
열리긴 하는데 인쇄·복사 메뉴가 흐리게 막혀 있어요권한 암호(제한만 걸림)필요 없음
그냥 열리고 다 돼요보호 없음풀 게 없음

직접 구분하지 않아도 괜찮아요. PDF 암호 풀기에 파일을 넣으면 먼저 파일을 살펴보고 '이 PDF는 열 때 암호가 필요해요', '암호 없이 열리지만 인쇄나 복사가 막힌 PDF예요', '이 PDF에는 암호나 제한이 없어요' 중 하나로 알려 줘요. 암호 입력칸은 열기 암호가 걸린 파일일 때만 나와요.

아는 암호로 푸는 순서

  1. PDF 암호 풀기에서 파일을 골라요.
  2. 암호를 물으면 PDF 뷰어에서 열 때 넣는 암호를 입력해요. 권한 암호를 받았다면 그 암호로도 돼요. 어느 쪽으로도 같은 키가 풀리기 때문이에요.
  3. '암호 풀기'를 누르고 저장해요. 파일 이름 끝에 -unlocked가 붙어서 원본과 헷갈리지 않아요.

쪽 내용은 그대로 두고 암호화만 벗겨요. 암호가 틀리면 '이 암호로는 열리지 않아요'라고 알려 주고 아무것도 저장하지 않아요. 어느 경우든 원본 파일은 바뀌지 않아요.

이럴 때 많이 풀어요.

  • 명세서를 모아 둘 때: 지난 명세서를 다시 볼 때마다 암호를 넣기 번거롭다면 암호 없는 사본을 만들어 안전한 곳에 보관해요.
  • 다른 도구에 넣어야 할 때: PDF 합치기, PDF 나누기, PDF JPG 변환 같은 도구는 열기 암호가 걸린 파일을 열지 못해요. 여러 달 치 명세서를 한 파일로 합치려면 먼저 하나씩 풀어야 해요.
  • 제출처가 암호 없는 파일을 달라고 할 때: 받는 쪽에서 암호를 모르면 파일을 열 수 없으니까요.

인쇄·복사만 막힌 PDF

암호 없이 열리는데 인쇄가 안 되거나 글자를 선택할 수 없다면 권한 암호로 제한이 걸린 파일이에요. 빈 사용자 암호로 이미 풀 수 있는 파일이라, PDF 암호 풀기는 아무것도 묻지 않고 제한을 없애요.

이 제한이 생각보다 약하다는 점도 알아 두면 좋아요. qpdf 문서는 PDF의 제한이 오로지 소프트웨어가 지켜 주는 것이고, 프로그램이 제한을 무시하지 못하게 막을 방법은 근본적으로 없다고 설명해요. 제한은 규칙을 따르는 뷰어가 지켜 주는 약속이지 자물쇠가 아니에요.

그래서 두 가지를 기억하세요. 문서를 남이 못 보게 하려면 제한이 아니라 열기 암호를 걸어야 해요. 그리고 제한은 바꿀 권리가 있는 파일에서만 푸세요. qpdf 문서도 암호를 푸는 기능이 저작권 보호나 만든 사람이 걸어 둔 제한을 우회하려는 용도가 아니라고 밝혀요. 출판사나 회사, 학교가 이유가 있어서 걸어 둔 제한일 수 있어요.

잊어버린 열기 암호는 풀 수 없어요

열기 암호는 멀쩡한 파일 위에 붙여 둔 스티커가 아니에요. 내용 자체가 암호화되어 있고, 그걸 풀 키를 얻으려면 암호가 있어야 해요. 암호가 없으면 PDF 뷰어도, 변환 도구도, 암호 해제 도구도 뒤섞인 데이터밖에 볼 수 없어요. qpdf 문서는 요즘 쓰는 AES-256 방식에서는 소유자 암호로 사용자 암호를 알아낼 방법도 없다고 설명해요.

PDF 암호 풀기는 암호를 추측하거나 하나씩 대입해 보지 않아요. 열기 암호를 모르면 PDF 뷰어에서 열 수 없는 것처럼 여기서도 풀 수 없어요. 대신 이렇게 해 보세요.

  • 파일과 함께 온 메일 본문이나 안내문을 다시 확인하세요. 보낸 곳이 암호나 암호를 만드는 규칙을 적어 두는 곳이 거기예요.
  • 보낸 곳(카드사, 은행, 회사 담당 부서 등)에 문의해서 암호를 확인하거나 다시 받으세요.
  • 내가 암호를 걸었던 파일이라면 암호를 걸기 전 원본이 남아 있는지 찾아보세요.

'모든 PDF 암호를 찾아 준다'는 서비스도 결국 추측하는 방식이고, 그러려면 내 문서를 남에게 넘겨야 해요.

푼 다음에는 이렇게 보관하세요

암호를 푼 사본은 누구든 열 수 있어요. 개인 폴더처럼 안전한 곳에 두고, 다 쓰면 지우고, 원래 암호 걸린 파일 대신 남에게 그대로 전달하지 마세요.

다시 잠가야 한다면, 예를 들어 여러 달 명세서를 합친 파일을 보관할 때는 PDF 암호 걸기를 쓰세요. AES-256으로 암호화하고, 원하면 인쇄와 복사도 막을 수 있어요. 새 암호는 꼭 적어 두세요. 저희를 포함해 누구도 되찾아 드릴 수 없어요. 암호를 바꾸고 싶을 때도 같아요. 지금 암호로 푼 다음 새 암호로 다시 걸면 돼요.

브라우저 안에서 푸는 이유

암호를 풀어야 하는 파일은 대개 명세서, 급여명세서, 세금 서류처럼 민감한 문서예요. 온라인 도구 상당수는 파일을, 때로는 암호까지 서버로 보내서 처리해요. 인플레이스의 PDF 암호 풀기는 qpdf를 웹어셈블리로 만들어 지금 보고 있는 브라우저 탭 안에서 돌리기 때문에, 파일과 암호가 기기 밖으로 나가지 않고 어디에도 저장되지 않아요.

  2. CSV를 엑셀에서 열면 한글이 깨지는 이유와 해결법CSV를 엑셀에서 열면 한글이 깨지는 이유(BOM 없는 UTF-8을 코드 페이지 949로 읽음)와, UTF-8 BOM 저장·'텍스트/CSV에서' 가져오기로 해결하는 방법을 정리했어요.
  3. 유튜브 영상을 MP3로 바꿔도 될까요?유튜브 약관이 다운로드에 대해 정한 내용, 저작권법 제104조의2·제136조·제30조 조문, 프리미엄 오프라인 저장과 유튜브 스튜디오 다운로드 같은 합법적인 대안을 정리했어요.
  4. PDF 용량 줄이기: 스캔 PDF가 큰 이유와 줄이는 법제출 서류나 메일 첨부가 용량 제한에 걸릴 때 PDF를 줄이는 방법. 스캔 PDF가 큰 이유, 압축 단계 고르는 법, Gmail 25MB 제한, 압축으로 안 줄어드는 경우를 정리했어요.
  5. 동영상 용량 줄이기: 메일로 보낼 수 있게 만드는 법동영상 용량을 정하는 해상도·비트레이트·길이, Gmail 25MB·Outlook 20MB 같은 첨부 한도, 자르고 압축하는 순서, 링크로 보내는 편이 나은 경우를 정리했어요.
  6. PDF 합치기: 기기별로 여러 PDF를 하나로 묶는 법맥 미리보기와 Finder의 PDF 생성, 아이폰 미리보기 앱의 파일에서 삽입, 윈도우·안드로이드에서 브라우저로 PDF를 합치는 방법과 합치기 전 쪽 정리·압축 요령을 정리했어요.
  7. PDF를 마크다운으로 바꿔서 AI에 넣기많은 AI 서비스가 PDF 쪽마다 글과 그림을 함께 읽어요. 마크다운으로 바꾸면 쪽 그림 몫이 빠져요. OpenAI·앤트로픽·구글 문서의 비용 구조, 직접 재 본 결과, PDF 그대로 넣는 게 나은 경우를 정리했어요.
