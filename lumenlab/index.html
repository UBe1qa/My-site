웹 도구는 창 안에서 그 도구의 계산이 그대로 돌고, 게임과 앱은 실제 화면을 보여 드려요. 아이콘 밑 한 줄은 그 도구가 결과를 확인한 방법이에요.

게임

휴대폰 게임이에요. 안드로이드부터 준비하고 있어요.

  • 병아리 구조대휴대폰 퍼즐 게임출시 준비 중
  • 캐슬업!휴대폰 방치형 디펜스플레이테스트 중

앱

맥 메뉴 막대 앱과 브라우저로 여는 앱이에요.

  • OwlightmacOS 메뉴 막대 앱App Store 출시 준비 중
  • 세트노트브라우저로 여는 앱

웹 도구

계산

날짜, 숫자, 월급을 과정까지 보이게 계산해요.

  • 며칠 계산기날짜 사이·디데이·만 나이정답 3,200여 개와 대조
  • 공학용 계산기공학 함수·물리 상수 계산정답 3,700여 개와 대조
  • 떼고얼마월급 실수령액·퇴직금 계산노동부 예제와 31전까지 같음

웹 도구

글과 파일

글자수를 세고, 파일을 바꾸고, 달력을 인쇄해요.

  • 인플레이스이미지·영상·PDF 파일 변환파일을 서버로 보내지 않음
  • 한장달력달력 인쇄·공휴일1900~2100년 요일 전부 시험
  • 칸칸글자 수 세기자동 테스트 3만 5천여 개
  • 오래QRQR코드 만들기만든 그림을 다시 읽어 확인

웹 도구

기기·시간·연습·모임

기기를 점검하고, 시간을 재고, 타자를 연습하고, 뽑기로 정해요.

  • 공평뽑기돌림판·사다리타기·팀 나누기10만 번 뽑아 카이제곱 검정
  • 체크벤치키보드·마우스·마이크 테스트판정 기준을 결과 옆에 밝힘
  • 토독한글·영어 타자 연습타수 세는 기준을 공개
  • 한바퀴타이머·스톱워치·세계 시간도시마다 zoneinfo와 대조
