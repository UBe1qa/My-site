루멘랩 개인정보 처리방침

시행일: 2026년 10월 18일. 루멘랩(Lumen Lab)이 lumenlab.page와 웹 도구 사이트를 운영하면서 이용자의 개인정보를 어떻게 처리하는지 적었어요.

한눈에 보기

  • 회원 가입과 로그인이 없어요. 루멘랩은 사이트에서 이름, 이메일, 전화번호 같은 개인정보를 받지 않아요.
  • 도구에 넣은 글, 숫자, 날짜, 명단, 파일과 마이크 소리, 카메라 영상은 이용자 브라우저 안에서만 처리하고 루멘랩 서버로 보내지 않아요.
  • 루멘랩이 직접 받는 개인정보는 이용자가 보낸 문의 메일(메일 주소와 내용)뿐이에요.
  • 웹 도구 사이트에는 Google 애드센스 광고가 나와요. 이때 Google 같은 광고 업체가 쿠키를 쓸 수 있어요(4번). lumenlab.page에는 광고가 없어요.
  • 맞춤 광고는 Google 광고 설정에서 끌 수 있어요.
  • 모든 사이트에 쿠키를 쓰지 않는 방문 통계(Cloudflare Web Analytics)가 있어요(3번).

1. 이 방침이 다루는 곳

  • lumenlab.page 루멘랩 홈과 만든 것 소개 페이지, 루멘랩 소개, 앱 지원 페이지
  • 웹 도구 사이트 아래 도구들이에요. 각 도구의 방침은 이 방침에 그 도구에만 해당하는 내용(이 기기에 남기는 항목 등)을 더한 것이에요.
  • 세트노트(setnote.lumenlab.page) 운동 기록 웹 앱이에요. 기록과 설정은 이 기기의 브라우저 저장소에만 남고 서버로 보내지 않아요. 광고가 없어요.
  • 캐슬업! 소개 사이트(castle-up.lumenlab.page) 아직 출시 전인 게임의 소개 페이지예요. 광고가 없고 이 기기에 남기는 것도 없어요. 방문 통계(3번)만 있어요.

3. 이 기기에 남는 것과 방문 통계

브라우저 저장소

사이트는 다음에 열 때 편하도록 일부 설정을 이용자 브라우저의 저장소(localStorage)에만 적어요. 서버로 보내지 않아요.

  • lumenlab.page 다른 언어 안내 띠를 닫거나 언어 단추를 눌러 고른 언어(lumen:langbar), 앱 지원 페이지에서 고른 언어(lumen:lang)
  • 웹 도구 사이트 도구마다 설정이나 최근 기록을 남기기도 해요. 남기는 항목은 1번 목록의 ‘이 도구의 방침’에 있어요.

브라우저 설정에서 사이트 데이터를 지우면 모두 사라져요.

방문 통계

사이트를 호스팅하는 Cloudflare가 방문 통계(Cloudflare Web Analytics)를 위해 작은 스크립트를 페이지에 넣어요. 본 페이지 주소, 직전 페이지 주소, 페이지가 열리는 데 걸린 시간, 브라우저 종류 같은 것을 모으고 쿠키는 쓰지 않아요. 도구에 넣은 내용은 여기에 실리지 않아요. 루멘랩은 Cloudflare 화면에서 집계된 숫자(방문 수, 많이 본 페이지 등)만 봐요.

접속 기록

페이지를 보내는 과정에서 Cloudflare가 IP 주소 같은 접속 정보를 처리하고 서비스를 안전하게 운영하려고 잠시 기록할 수 있어요. 도구에 따라 글꼴 같은 파일을 공개 전송망(jsDelivr 등)에서 받기도 하는데, 그때도 다른 웹 요청처럼 접속 IP가 전달돼요. 어느 쪽도 도구에 넣은 내용은 받지 않아요.

4. 광고와 쿠키(웹 도구 사이트)

웹 도구 사이트는 Google 애드센스로 광고를 보여 줘요. lumenlab.page와 앱의 지원·방침 페이지에는 광고가 없어요.

  • Google을 비롯한 제3자 광고 업체는 쿠키를 써서 이용자가 이 사이트나 다른 사이트에 방문한 기록을 바탕으로 광고를 보여 줄 수 있어요.
  • 광고 때문에 Google 같은 제3자가 이용자 브라우저에 쿠키를 넣거나 읽을 수 있고, 웹 비콘(눈에 보이지 않는 작은 이미지) 같은 기술로 정보를 모을 수 있어요.
  • Google이 이 정보를 어떻게 쓰는지는 파트너 사이트에서 Google이 데이터를 사용하는 방식에서 볼 수 있어요.

맞춤 광고에 쓰이는 정보(행태정보)

모으는 곳
Google(애드센스)
항목
광고 쿠키 식별자, 본 페이지 주소와 방문 시각, 광고를 보거나 누른 기록, 브라우저·기기 정보 같은 웹 이용 기록
방법
웹 도구 페이지가 열릴 때 광고 코드가 쿠키와 웹 비콘으로 자동으로 모아요.
목적
광고를 보여 주고, 관심사에 맞는 광고를 고르고, 광고 성과를 재요.
보유 기간
Google 개인정보처리방침을 따라요.
  • 맞춤 광고는 Google 광고 설정에서 끌 수 있어요. 다른 광고 업체의 맞춤 광고는 aboutads.info에서 끌 수 있어요.
  • 쿠키는 브라우저 설정에서 막거나 지울 수 있어요. 막아도 도구는 그대로 쓸 수 있고, 맞춤이 아닌 광고가 나올 수 있어요.

광고 정보는 Google이 직접 모으고 처리해요. 루멘랩은 이 정보를 받거나 저장하지 않고, 애드센스가 주는 집계 보고서(광고 노출 수, 수익 등)만 봐요.

5. 제3자 제공, 처리 위탁, 국외 이전

루멘랩은 이용자의 개인정보를 제3자에게 제공하지 않아요. 아래 일은 맡기고 있어요(처리 위탁). 두 곳 모두 미국 회사라, 맡긴 정보가 국외(미국 등) 서버에서 처리될 수 있어요(국외 이전).

Cloudflare, Inc.
사이트 호스팅과 방문 통계, contact@lumenlab.page로 온 메일을 루멘랩 메일함으로 전달. 옮겨지는 정보: 접속 정보, 방문 통계 항목(3번), 보낸 메일의 주소와 내용. 개인정보 문의: privacyquestions@cloudflare.com
Google LLC
루멘랩 메일함(Gmail)에 문의 메일 보관. 옮겨지는 정보: 보낸 메일의 주소와 내용. 개인정보 문의: googlekrsupport@google.com

정보는 사이트를 열거나 메일을 보낼 때 인터넷으로 암호화해 옮겨지고, 보유 기간은 2번을 따라요. 국외 이전을 원하지 않으면 메일을 보내지 않으면 돼요. 다만 이때는 답변을 드릴 수 없어요. 광고 정보(4번)는 Google이 직접 모으는 것이라 루멘랩이 넘기는 것이 아니에요.

6. 파기 절차와 방법

  • 보유 기간이 끝나거나 목적을 이루면 지체 없이 파기해요.
  • 전자 파일은 되살릴 수 없는 방법으로 지우고, 종이 문서는 쓰지 않아요.
  • 브라우저 저장소에 남은 설정은 이용자가 사이트 데이터를 지우면 파기돼요.

7. 이용자와 법정대리인의 권리

  • 이용자(만 14세 미만이면 법정대리인)는 언제든 개인정보의 열람, 정정, 삭제, 처리 정지를 요청할 수 있어요. 아래 메일로 보내 주시면 지체 없이 처리해요.
  • 루멘랩이 보관하지 않는 정보(브라우저 저장소, Google이 처리하는 광고 정보)는 각각 브라우저 설정과 Google 계정·광고 설정에서 관리할 수 있어요.
  • 사이트는 어린이를 주 대상으로 하지 않고, 누구의 개인정보도 사이트에서 직접 모으지 않아요.

8. 안전성 확보 조치

  • 이용자가 도구에 넣은 내용을 받는 서버가 없어서 루멘랩 쪽에 쌓이는 입력 정보가 없어요.
  • 모든 사이트는 암호화된 연결(HTTPS)로만 열려요.
  • 문의 메일은 루멘랩만 볼 수 있는 메일함에 두고, 접근할 수 있는 사람을 운영자로 한정해요.
