도구를 만드는 기준

  • 열자마자 바로 써요. 회원 가입, 설치, 하루 사용 제한이 없어요.
  • 넣은 내용은 이 기기 안에서 처리해요. 날짜, 글, 명단, 파일을 루멘랩 서버로 보내지 않고 브라우저 안에서 계산하고 바꿔요. 루멘랩에는 그런 내용을 받는 서버가 없어요.
  • 기준과 출처를 밝혀요. 답이 기준에 따라 갈리는 곳(글자 수의 공백, 만 나이, 6÷2(1+2) 같은 것)은 어느 기준인지 화면에 적고, 법이나 공식 자료를 따르는 숫자는 출처와 확인한 날을 같이 적어요.
  • 계산하고 세는 도구는 따로 구한 정답과 맞춰 봐요. 계산하고 세는 부분은 화면과 떼어 두고, 다른 방법으로 구한 기준값과 대조하는 자동 시험을 붙여요. 도구마다 무엇을 확인했는지는 바로 아래에 있어요.
  • 못 하는 것은 못 한다고 적어요. 웹페이지라서 알 수 없는 것, 아직 없는 기능, 확인하지 못한 것을 도구 화면과 소개에 그대로 적어요.
  • 없는 숫자를 만들지 않아요. 사용자 수, 평점, 후기처럼 확인하지 않은 숫자나 말은 쓰지 않아요.

도구마다 확인하고 밝혀 둔 것

각 도구의 소개 페이지에 적은 것을 한곳에 모았어요. 도구 이름을 누르면 바로 써 볼 수 있고, 자세한 기준과 출처는 '기준과 출처'를 누르면 그 도구 사이트에서 볼 수 있어요.

며칠 계산기 날짜 사이·디데이·만 나이
다른 방식(파이썬 날짜 라이브러리)으로 따로 구한 정답 3,200여 개와 대조하는 자동 시험을 통과해야 배포해요. 기준과 출처 →
공학용 계산기 공학 함수·물리 상수 계산
파이썬 수학 라이브러리(sympy·mpmath·scipy·numpy)로 따로 구한 정답 3,700여 개와 결과를 자동으로 맞춰 보고, 물리 상수는 NIST 표와 한 자리씩 비교했어요. 기준과 출처 →
떼고얼마 월급 실수령액·퇴직금 계산
요율과 상한·하한은 법령과 공단·부처 자료를 직접 열어 확인한 것만 쓰고, 항목마다 출처와 확인한 날을 표로 공개해요. 퇴직금은 고용노동부 예제의 1일 평균임금 88,641원 31전까지 같게 나와요. 기준과 출처 →
인플레이스 이미지·영상·PDF 파일 변환
파일은 서버로 보내지 않고 브라우저 안에서 바꿔요. 변환에 쓰는 오픈소스 라이브러리(Mediabunny, LAME, libheif, PDF.js, pdf-lib, qpdf, SheetJS 등)를 소개에 모두 적었어요. 기준과 출처 →
오래QR QR코드 만들기
정적 QR만 만들어서 넣은 주소가 그림 안에 그대로 들어가고, 오래QR이 멈춰도 코드는 멈추지 않아요. 만든 그림은 바로 다시 읽어 찍히는지 확인해요. 기준과 출처 →
한장달력 달력 인쇄·공휴일
한국 공휴일은 「관공서의 공휴일에 관한 규정」대로 계산하고, 2026·2027년은 공식 발표와 한 날씩 맞춰 봤어요. 요일은 1900~2100년의 모든 날을 검사해요. 기준과 출처 →
칸칸 글자 수 세기
세는 로직을 자동 테스트 3만 5천여 개로 확인해요. 기준값은 파이썬 표준 코덱·유니코드 라이브러리, twitter-text, 서로 다른 SMS 계산기 세 가지로 따로 구했어요. 기준과 출처 →
공평뽑기 돌림판·사다리타기·팀 나누기
뽑을 때마다 브라우저의 crypto.getRandomValues()로 새 씨앗을 받아 쓰고, 10만 번씩 뽑아 보는 카이제곱 검정을 포함한 자동 테스트 500여 개로 고르게 나오는지 확인해요. 결과 링크로 누구나 같은 결과를 다시 계산할 수 있어요. 기준과 출처 →
토독 한글·영어 타자 연습
타수와 WPM을 세는 기준을 공개하고(‘다섯 글자 = 한 단어’는 타자 연구에서 쓰는 정의로, Dhakal 외, CHI 2018에 적혀 있어요), 책·기사·노래 가사 같은 남의 글은 연습 글에 넣지 않았어요. 기준과 출처 →
한바퀴 타이머·스톱워치·세계 시간
도시 시각은 IANA 시간대 자료로 계산하고, 2026년에 바뀐 캐나다 세 주·모로코 규칙은 따로 반영했어요. 시험에서는 도시마다 파이썬 zoneinfo 값과 대조해요. 기준과 출처 →
체크벤치 키보드·마우스·마이크 테스트
판정마다 기준(키보드 채터링 30ms, 마우스 더블클릭 50ms 등)을 결과 옆에 밝히고, 웹페이지로는 알 수 없는 것(마우스의 실제 USB 폴링레이트 등)은 알 수 없다고 적어 둬요. 기준과 출처 →

계속 고치는 일

도구가 따르는 기준 가운데는 해마다 바뀌는 것이 있어요. 바뀌는 때를 정해 두고 고쳐요.

  • 떼고얼마 4대 보험 요율과 상한·하한, 근로소득 간이세액표가 새로 나오면 반영해요. 2027년 몫은 지금도 확정된 것, 의결된 것, 아직 안 정해진 것으로 나눠 보여 줘요.
  • 한장달력 다음 해 월력요항이 발표되면(해마다 6월 말쯤) 그해 공휴일을 공식 자료로 바꿔요. 발표 전인 해는 ‘공식 발표 전 자료’라고 표시해요.
  • 한바퀴 나라나 지역이 서머타임과 시간대 규칙을 바꾸면 반영해요. 2026년에 바뀐 캐나다 세 주와 모로코가 그 예예요.
  • 모든 도구 틀린 결과를 알려 주시면 확인해서 고치고, 글을 고치면 그 글에 고친 날을 적어요.
