Keyboard typing double letters: how to confirm chattering

Lumen Lab · Last checked Oct 10, 2026

CheckbenchKeyboard, mouse and mic testsOpen ↗

If one key sometimes types two letters, you can confirm it in about a minute. Open the keyboard tester, tap the suspect key slowly thirty times and read the Double-typing line. If it says “none seen”, the key behaved. If it names the key, the tester caught a second press that came too soon after the first to be you.

What the tester counts as double-typing

The tester watches the gap between letting a key go and that same key going down again. If the gap is under 30 ms, it counts one possible double-typing. 30 ms is this site’s own rule, not an official standard, and you can change it under Details and settings.

The gap is measured from release to the next press, not from press to press. That matters because a faulty key can fire again right as you let go, even when your own presses are far apart.

A test that takes one minute

  1. Open the keyboard tester and pick your layout.
  2. Tap the suspect key about once per second, thirty times. Do not rush: you want every double press to be the keyboard’s doing.
  3. Read Double-typing. “1 key suspected” with the key drawn in orange means at least one press doubled.
  4. Open Details and settings to see Recent presses. Each line shows how long after release the press arrived.
  5. Repeat on a key you trust. If that one stays clean, the problem is the key and not your typing.

Things that look like chattering but are not

  • Holding a key. Letters that repeat while you hold a key down are the system’s key repeat. The tester ignores those repeats and never counts them.
  • Typing software. Text expanders, macros or remapping tools can send extra keys. Test with them closed.
  • One program only. If the tester stays clean but one app doubles letters, look at that app’s settings first.

If the tester confirms it

Try the keyboard on another computer or another USB port and run the same test. If the same key doubles there too, the fault travels with the keyboard. Keep a note of the key and how often it happened out of thirty taps. It is useful to have when you contact the seller or the maker.

Changing the limit in the tester does not fix anything. It only changes what this page counts.
