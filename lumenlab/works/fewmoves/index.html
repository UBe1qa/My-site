불러오는 중

화살표 굵기가 그 레이팅대에서 그 수를 두는 비율이에요. 숫자는 오프닝 트레일 사이트의 리체스 1억 7,493만 판 자료를 그대로 읽어요.

레이팅만 고르면 내 상대가 실제로 두는 수가 보여요

  1. 레이팅대 고르기‘지도’ 위 ‘리체스 레이팅’에서 내 레이팅대를 누르면 표와 화살표가 그 레이팅대 사람들이 둔 수와 비율로 바뀌어요.
  2. 수 두기판에서 말을 움직이거나 표에서 수를 누르면 다음 국면으로 가요. 수마다 메인·대안·실수 표시가 붙고, 이름 있는 국면이면 오프닝 이름과 해설 링크가 떠요.
  3. 해설 읽기‘오프닝’에서 81개 가운데 하나를 열면 메인라인을 수마다 이유와 함께 따라가는 판, 함정과 응징, 양쪽 계획, 세부 갈래, 레이팅대별 응수 표가 있어요.
  4. 테스트와 연습‘테스트’에서 2분 동안 국면 10개를 풀면 내 단계가 나와요. 해설 끝 ‘백으로 연습’이나 ‘흑으로 연습’을 누르면 상대가 내 레이팅대에서 실제로 나온 수로 받아치고, 틀린 수는 복습에 들어가요.

확인하고 밝혀 둔 것

리체스가 공개한 2026년 8~10월 레이팅 대국을 직접 세었고, 메인·대안·실수 표시는 리체스 평가 데이터베이스의 엔진 점수로 가르며, 해설의 모든 수순은 사이트를 만들 때 체스 규칙 프로그램(chess.js)으로 둬 보고 메이트라고 적은 함정은 실제 체크메이트인지 확인해요.

이름을 오프닝 트레일로 바꾸고 숫자를 열 배로 늘렸어요

  1. 2026. 11. 5.

    이름을 외울수에서 오프닝 트레일로 바꾸고, 리체스 8⁠~⁠10월 대국 1억 7,493만 판으로 숫자를 다시 셌어요.

  2. 2026. 11. 5.

    오프닝 지도, 2분 테스트, 레이팅별 추천 오프닝을 더하고, 수마다 엔진 평가로 메인·대안·실수를 표시했어요.

  3. 2026. 11. 4.

    카탈란, 그륀펠트, 버드, 그롭 같은 오프닝 50개에 해설을 더하고, 리체스에서 판이 있는 오프닝 계열은 모두 어느 해설엔가 속하게 했어요.

  4. 2026. 11. 4.

    해설에서 승률·빈도를 말한 문장을 직접 센 숫자에 맞춰 고쳤어요(나이도르프 6수째, 잉글룬드 성적 등).

  5. 2026. 11. 4.

    이탈리안 해설에서 4.Ng5가 통하는 때와 3...Nd4 함정 설명을 바로잡았어요.

  6. 2026. 11. 4.

    레이팅이 오르면 어떤 오프닝이 늘고 주는지 정리한 가이드 1편을 올렸어요.

  7. 2026. 11. 4.

    탐색기, 오프닝 해설 31개, 간격 반복 연습을 한국어와 영어로 열었어요.
