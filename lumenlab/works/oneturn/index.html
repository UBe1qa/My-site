타이머·스톱워치·세계 시간

도시마다 zoneinfo와 대조

열기 ↗

남은 시간이 시계판에 보이는 타이머, 랩 기록 스톱워치, 알람, 세계 시간. 다른 탭에서도 제때 울리고, 도시마다 서머타임 바뀌는 날까지 보여 줘요.

  • 122개세계 시간 도시
  • 8개타이머 동시에
  • 1/100초스톱워치

바로 써 보기

불러오는 중

판을 끌어 1분 단위로 맞추고, 돌기 시작하면 판 한 바퀴가 맞춘 시간에 맞춰 바뀌어요.

‘5분’ 단추 하나만 누르면 바로 돌아요

  1. 시간 단추 누르기‘누르면 바로 시작’ 아래 ‘1분’부터 ‘1시간’까지 단추 8개 가운데 하나를 누르면 그 시간으로 바로 돌아요.
  2. 시·분·초 직접 넣기‘직접 맞추기’에 시간·분·초를 넣고 ‘시작’을 누르면, 청록 부채꼴이 남은 시간을 보여 주며 12시 쪽으로 줄어들어요.
  3. 끝날 소리 미리 듣기‘소리’에서 ‘종’·‘삐삐’·‘부드럽게’ 가운데 하나를 고르고 ‘미리 듣기’를 누르면 끝날 때 날 소리를 먼저 들어 봐요.
  4. 이름 붙여 여러 개이름 칸에 이름을 적고 ‘타이머 더하기’로 더 돌리면, 끝날 때 어느 타이머인지 이름으로 띄워 줘요.

이런 것도 돼요

  • 스톱워치랩 기록·CSV 저장
  • 알람5분 뒤 다시 울리기
  • 세계 시간·시차서머타임 바뀌는 날까지

확인하고 밝혀 둔 것

도시 시각은 IANA 시간대 자료로 계산하고, 2026년에 바뀐 캐나다·모로코 규칙은 따로 반영했어요. 시험에서는 도시마다 파이썬 zoneinfo 값과 대조해요.

도시 시각
브라우저에 든 IANA 시간대 자료로 계산해요. 2026년에 바뀐 캐나다·모로코 규칙은 브라우저 자료가 예전 것이어도 맞게 따로 넣어 뒀고, 그럴 땐 세계 시간 화면에 알려요.IANA 변경 기록
다른 탭에서 울리는 때
크롬은 숨은 지 5분 넘은 탭에서, 타이머를 짧게 여러 번 이어 거는 방식은 1분에 한 번만 확인하기도 해요. 그래서 남은 시간은 끝나는 시각에서 거꾸로 계산해요.Chrome for Developers: Heavy throttling of chained JS timers beginning in Chrome 88
화면 꺼짐·다른 앱
화면이 꺼지거나 다른 앱으로 가면 브라우저가 페이지를 얼릴 수 있고, 얼어 있는 동안에는 타이머가 돌지 않아요.Chrome for Developers: Page Lifecycle API
화면 켜 두기
‘화면 켜 두기’는 크롬 84, 사파리 16.4, iOS 사파리 18.4, 파이어폭스 126부터 되고, 안 되는 브라우저에선 ‘이 브라우저는 화면 켜 두기를 못 해요’라고 떠요.MDN: Screen Wake Lock API 브라우저 지원
이 기기에 남는 것
타이머 이름과 끝나는 시각, 스톱워치 랩, 알람, 도시 목록, 설정은 이 브라우저에만 적고 서버로 보내지 않아요.한바퀴 개인정보 처리방침(저장하는 것 6가지)
