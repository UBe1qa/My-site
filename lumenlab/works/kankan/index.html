글자 수 세기

자동 테스트 3만 5천여 개

열기 ↗

글자수를 공백·줄바꿈·바이트 기준별로 나란히 세어요. 자소서, 나이스 생기부, SNS 한도, 원고지까지.

  • 3만 5천여 개자동 테스트
  • 0·1·2자줄바꿈 세는 법
  • 이 기기 안글이 밖으로 안 나감

바로 써 보기

불러오는 중

아래 원고지는 칸칸이 200자 원고지에 놓는 방식 그대로 첫 장을 그려요.

글을 붙여 넣으면 숫자 8개가 한꺼번에 바뀌어요

  1. 글 붙여 넣기글을 붙여 넣거나 ‘예시 글 넣어 보기’를 누르면 ‘공백 포함’과 ‘공백 제외’ 글자 수가 바로 나와요.
  2. 바이트와 원고지 보기그 아래에서 ‘바이트’(UTF-8, EUC-KR), ‘단어’, ‘문장’, ‘줄’, ‘원고지’ 장 수도 같이 바뀌어요.
  3. 줄바꿈 기준 맞추기‘줄바꿈은 1자로 셈’ 옆 ‘바꾸기’를 눌러 ‘0자’, ‘1자’, ‘2자’ 중 글을 낼 곳과 같은 것을 고르면 다시 세어요.
  4. 목표 글자 수 넣기‘목표 글자 수 넣기’에 숫자를 넣고 ‘공백 포함’, ‘공백 제외’, ‘UTF-8 바이트’ 중 기준을 고르면 얼마나 남았는지, 넘었는지 알려 줘요.

이런 것도 돼요

  • 자소서 글자수문항마다 남은 글자
  • 바이트 계산기UTF-8·EUC-KR 나란히
  • 나이스 생기부기재요령 최대 바이트로
  • SNS 글자수X·인스타·스레드 한도
  • 원고지200자 원고지 몇 장

확인하고 밝혀 둔 것

세는 로직을 자동 테스트 3만 5천여 개로 확인해요. 기준값은 파이썬 표준 코덱·유니코드 라이브러리, twitter-text, 서로 다른 SMS 계산기 세 가지로 따로 구했어요.

SNS 글자 수 한도 10가지를 2026년 10월 10일에 서비스마다 공식 문서로 확인했어요

칸칸 기준표

한 글자
사람이 보는 한 글자를 1자로 세어요. 브라우저의 Intl.Segmenter가 글자 묶음을 나눠요.유니코드 표준 부속서 UAX #29
UTF-8 바이트
영문과 숫자는 1바이트, 한글은 1자에 3바이트로 세어요.RFC 3629: UTF-8
X 게시물
가중치로 280까지예요. 한글과 이모지는 2, 주소는 길이와 상관없이 23으로 세고, 테스트는 npm twitter-text 3.1.0과 견줬어요.X 공식 문서 ‘Counting characters’ · 확인 2026. 10. 10.
유튜브 설명
글자 수가 아니라 UTF-8 5,000바이트까지예요. 한글만 쓰면 계산으로는 1,666자쯤 들어가요.유튜브 공식 문서 · 확인 2026. 10. 10.
블루스카이 게시물
300 글자소이고, UTF-8로 3,000바이트 안이어야 해요. 둘 중 하나만 넘어도 넘었다고 표시해요.블루스카이 공식 문서 · 확인 2026. 10. 10.

공식 문서에 세는 단위가 없는 한도 6가지는 UTF-16 단위로 세어서, 이모지가 많은 글은 실제 화면과 조금 다를 수 있어요.

가이드 4편

  1. 같은 글인데 글자 수가 다르게 나오는 이유
  2. 나이스 500자는 왜 1,500바이트일까
  3. 이모지 하나는 몇 글자일까
  4. 한글은 왜 2바이트이기도 하고 3바이트이기도 할까
