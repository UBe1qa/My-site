키보드·마우스·마이크 테스트

판정 기준을 결과 옆에 밝힘

열기 ↗

키보드·마우스·마이크·웹캠·스피커·모니터·게임패드를 한 화면에서 테스트해요. 소리와 영상은 기기 밖으로 안 나가요.

  • 8가지기기 테스트
  • 30ms두 번 찍힘(채터링) 기준
  • 설치 없음가입도 없어요

바로 써 보기

불러오는 중

위 숫자는 지금 보고 있는 이 화면의 주사율이고, 키보드는 같은 키를 뗀 뒤 30ms 안에 다시 눌리면 채터링 의심으로 알려요.

첫 화면에서 키보드부터 스피커까지 7가지를 하나씩 확인해요

  1. 아무 키나 누르기아무 키나 누르면 그림 자판에서 그 키에 불이 들어오고, 키보드 칸에 ‘키가 들어와요’가 떠요.
  2. 마우스 누르고 굴리기단추를 누르고 휠을 굴리면 ‘마우스가 들어와요’가 뜨고, 빠르게 움직이면 ‘1초에 알려 주는 횟수(추정)’에 숫자가 나와요.
  3. 마이크·카메라 허용하기‘마이크 확인하기’를 눌러 허용한 뒤 말하면 ‘소리를 잡아요’가, ‘카메라 확인하기’를 눌러 허용하면 ‘카메라가 돼요’가 떠요.
  4. 스피커 한쪽씩 듣기‘왼쪽’이나 ‘오른쪽’을 누르면 그쪽으로 작은 소리가 1.2초 나고, 끝나면 ‘소리를 냈어요’가 떠요.

이런 것도 돼요

  • 키보드 테스트안 눌리는 키·채터링
  • 마우스 테스트단추·휠·더블클릭
  • 마이크 테스트녹음해서 바로 듣기
  • 웹캠 테스트해상도와 초당 장 수
  • 스피커 테스트왼쪽·오른쪽 소리
  • 불량화소 테스트전체 화면 단색
  • 주사율 테스트내 모니터 Hz
  • 게임패드 테스트스틱 쏠림·떨림

확인하고 밝혀 둔 것

판정마다 기준(키보드 채터링 30ms, 마우스 더블클릭 50ms 등)을 결과 옆에 밝히고, 웹페이지로는 알 수 없는 것(마우스의 실제 USB 폴링레이트 등)은 알 수 없다고 적어 둬요.

동시에 눌린 키가 6개에서 멈추면 USB 기본 보고 형식 때문일 수 있어요

체크벤치 기준표

마이크·카메라 권한
단추를 누를 때만 getUserMedia로 권한을 물어요. 막히면 브라우저가 준 오류를 보고 사이트 권한이 막혔는지, 운영체제 설정이 막았는지, 장치가 없는지 나눠 알려 줘요.MDN: MediaDevices.getUserMedia() · 확인 2026. 10. 10.
마이크 소리 크기
울림 제거·소음 억제·자동 음량을 꺼 달라고 한 채로 재요. 가장 큰 소리를 0 dBFS로 두는 눈금에서 −45 dBFS를 넘으면 ‘소리를 잡아요’, 꼭대기에서 잘리면 ‘너무 커요(잘림)’이 떠요.체크벤치 소개
주사율
requestAnimationFrame으로 화면 120장 간격을 재서 중앙값을 써요. 흔한 값과 1% 안이면 ‘약’을 붙이고, 제때 온 화면이 75%⁠보다 적으면 값을 말하지 않아요.체크벤치 소개
동시에 눌린 키
같은 순간 눌려 있는 키를 Shift·Ctrl까지 모두 세요. USB 키보드의 기본 보고 형식은 조합 키 말고 6개까지 담아요.USB-IF, HID 장치 규격 1.11 · 확인 2026. 10. 10.
게임패드 스틱
가만히 둔 위치의 평균이 5% 미만이면 가운데, 15% 이상이면 쏠림으로 봐요. Gamepad API 값을 거르지 않고 쓰니, 작은 쏠림을 무시하는 게임에선 안 느껴질 수 있어요.마이크로소프트 문서: XInput 시작하기의 Dead Zone 칸 · 확인 2026. 10. 10.
기기에 남는 것
마이크 소리, 녹음, 카메라 영상, 사진은 탭 안에서만 처리하고 어디에도 보내지 않아요. 브라우저에는 자판 배열과 채터링·더블클릭 기준 같은 설정만 남겨요.체크벤치 개인정보 처리방침

판정 기준은 공식 표준이 아니라 체크벤치가 정한 값이고, 화상회의 프로그램은 소리를 따로 다듬어서 거기서 들리는 소리와 다를 수 있어요.
