세트노트 SetNote

브라우저로 여는 앱 · 홈 화면에 추가

지금 쓸 수 있어요

열기 ↗

루틴을 저장하고, 세트마다 지난번 무게와 횟수를 보면서 기록해요.

  • 가입 없음휴대폰 브라우저에서 바로
  • 인터넷 없이홈 화면에 추가하면
  • 기기 안에만기록을 서버로 안 보내요

미리 보기

실제 앱 화면이에요. 예시로 이틀 운동을 적어 보고 찍었어요.

지난번과 같으면 세트마다 체크 한 번이면 돼요

  1. 추천 루틴 고르기처음 열면 나오는 ‘푸시 데이’·‘풀 데이’·‘레그 데이’ 가운데 하나에서 ‘바로 시작’을 누르면 그 루틴으로 운동이 바로 열려요.
  2. 무게·횟수 적고 체크세트마다 ‘kg’과 ‘회’ 칸에 적고 오른쪽 체크를 누르면 기록되고, 칸을 비워 두면 흐리게 보이는 값으로 들어가요.
  3. 쉬는 시간 재기체크하면 ‘휴식’ 타이머가 기본 90초로 흐르고, ‘−15’·‘+15’로 15초씩 바꾸거나 ‘건너뛰기’로 넘겨요. 휴대폰이 무음이면 끝 소리가 안 날 수 있어요.
  4. 저장하고 끝내기위의 ‘완료’에 이어 ‘저장하고 끝내기’를 누르면 ‘총 볼륨’과 ‘지난번과 비교’가 나오고, 다음엔 ‘지난번’ 칸에 오늘 값이 떠요.

더 알아보기

  • 루틴 저장자주 하는 운동 순서를 한 번에
  • 지난번과 바로 비교세트마다 지난번 무게와 횟수
  • 세트 사이 쉬는 시간끝날 때 소리로 알려 줘요
  • 쌓이는 기록최고 무게, 추정 1RM, 이번 주 볼륨

밝혀 둔 것

기록은 이 기기에만 저장되고 서버로 보내지 않아요. 위 화면은 실제 앱에 예시 운동 두 번을 적어 넣고 찍은 거예요.

어떤 앱인지 →

추정 1RM은 무게 × (1 + 횟수/30)로 계산해요

세트노트 기준표

기록이 지워지는 때
설정의 ‘저장 위치’에 ‘이 브라우저에만 저장 중’이라고 떠요. 브라우저 데이터를 지우면 기록도 사라지고, 홈 화면에 설치한 앱은 앱을 지울 때 사라져요.세트노트 앱 › 설정 › ‘저장 위치’
백업 파일
‘백업 내보내기’는 루틴과 모든 기록을 JSON 파일 하나로 받아요. ‘백업 가져오기’ 때 같은 항목이 이미 있으면 백업 내용으로 바뀌어요.세트노트 앱 › 설정 › ‘백업’
추정 1RM
Epley 공식이에요. 1회만 했으면 그 무게를 그대로 써요.세트노트 앱 › 운동을 누르면 나오는 기록 화면
신기록
운동마다 이번에 가장 높은 추정 1RM이 지금까지 최고보다 높으면 끝 화면에 신기록으로 떠요. 맨몸 운동과 처음 한 운동은 빼요.세트노트 앱 › 운동을 끝낸 뒤 요약 화면
볼륨
체크한 세트의 무게 × 횟수를 모두 더해요. 체크하지 않은 세트는 저장되지 않아요.세트노트 앱 › 운동을 끝낸 뒤 ‘총 볼륨’
광고
세트노트에는 광고가 없어요.루멘랩 개인정보 처리방침
