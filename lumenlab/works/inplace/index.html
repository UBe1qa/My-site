파일을 서버로 보내지 않음

영상에서 MP3 뽑기, 사진·HEIC 바꾸기, PDF 합치기, CSV·엑셀 변환을 파일을 올리지 않고 브라우저에서 해요.

불러오는 중

품질을 낮추면 용량이 줄고, 확대 그림에서 뭉개지는 곳이 보여요.

파일을 넣으면 그 파일에 맞는 도구만 골라 보여 줘요

  1. 파일 고르기첫 화면에서 ‘파일 고르기’를 누르거나 동영상·오디오·이미지·PDF·CSV·엑셀 파일을 끌어다 놓아요.
  2. 할 일 고르기‘이 파일로 무엇을 할까요?’ 아래에 그 파일을 여는 도구만 카드로 뜨고, 하나를 누르면 같은 화면에서 바로 열려요.
  3. 설정하고 실행하기동영상에서 소리를 뽑는다면 ‘형식’과 ‘비트레이트’(기본 192kbps)를 고르고 예상 크기를 본 뒤 ‘오디오 추출하기’를 눌러요.
  4. 결과 받기‘다 됐어요’ 카드에 결과 크기와 걸린 시간이 나오고, ‘받기’(여러 개면 ‘모두 받기 (ZIP)’)를 누르면 기기에 저장돼요.

이런 것도 돼요

  • HEIC → JPG아이폰 사진을 JPG로
  • 사진 용량 줄이기줄어든 KB를 바로 보며
  • JPG → PDF사진 여러 장을 PDF 하나로
  • PDF 합치기순서를 바꿔 하나로
  • 동영상 → MP3소리만 뽑아내기
  • 동영상 용량 줄이기보내기 좋은 크기로

확인하고 밝혀 둔 것

파일은 서버로 보내지 않고 브라우저 안에서 바꿔요. 변환에 쓰는 오픈소스 라이브러리(Mediabunny, LAME, libheif, PDF.js, pdf-lib, qpdf, SheetJS 등)를 소개에 모두 적었어요.

인플레이스 기준표

동영상 형식 바꾸기
새 형식에 그대로 담을 수 있는 영상과 소리는 다시 압축하지 않고 옮겨 담아서 화질이 그대로예요. MP4·MOV로 바꿀 땐 아이폰·맥에서 열리게 VP9·AV1 영상은 H.264(안 되면 HEVC)로, Opus·Vorbis 소리는 AAC로 다시 만들어요.Mediabunny (브라우저의 WebCodecs 사용)
MP3 음질
LAME 3.100으로 128·192·320kbps 가운데 하나로 만들어요. 동영상에서 뽑을 땐 192kbps가 기본이고, 오디오 파일은 원본이 150kbps보다 낮으면 128kbps로 시작해요.LAME 프로젝트
HEIC 사진
사파리에선 브라우저가 직접 읽고, 크롬·엣지·파이어폭스에선 페이지에 든 libheif로 풀어요. 촬영 날짜와 GPS 위치는 새 파일에 옮기지 않아요.libheif-js (libheif)
PDF 압축
사진과 스캔 그림만 JPEG로 다시 저장하고(기본 ‘균형’: 긴 변 약 1600픽셀, 품질 70), 파일 구조도 더 작게 묶어요.qpdf 문서: 객체 스트림과 스트림 압축 옵션 · 확인 2026. 10. 6.
PDF 암호
PDF 암호 가운데 가장 강한 AES-256으로 걸어요. ‘인쇄와 복사도 막기’는 뷰어가 지켜 주는 제한이라, 내용을 지키는 건 열기 암호예요.qpdf 문서: PDF 암호화(사용자 암호와 소유자 암호, 보안 제한) · 확인 2026. 10. 6.
엑셀용 CSV
엑셀은 파일 맨 앞에 BOM이라는 표시가 있어야 한글을 UTF-8로 알아봐서, ‘엑셀에서 한글 안 깨지게 (UTF-8 BOM)’가 처음부터 켜져 있어요.Microsoft 지원: Excel에서 CSV UTF-8 파일을 올바르게 열기 · 확인 2026. 10. 6.

실제 한계는 기기 메모리라 아주 큰 영상은 휴대폰에서 실패할 수 있고, 워드·한글(HWP)·파워포인트를 PDF로 바꾸기와 글자 인식(OCR)은 아직 없어요.
