    How to test

    1. Pick the layout that looks like your keyboard.
    2. Press each key once. Pressed keys stay tinted.
    3. Hold several keys together to see how many register at once.
    4. Tap one key many times to look for double-typing.

    What the results mean

    A key that never lights up did not reach the browser. Try it in another app before you blame the keyboard, because some keys (for example some Fn combinations and system shortcuts) are handled by the system and may never arrive on a web page.

    How double-typing is judged

    If the same key is pressed again within 30 ms of being released, this site counts it as possible double-typing (often called chattering). 30 ms is this site’s own rule, not an official standard. You can change it under Details and settings.

    Keys held at once

    Hold keys down together and the tester shows the largest number it saw at the same moment. If a key stops registering once others are held, your keyboard limits that combination.

    Questions

    Why does a key not light up?

    Either the keyboard did not send it, or the system kept it. Media keys, the Fn key on many laptops and some system shortcuts may not reach a web page. Test the key in a text editor as well.

    Does this keyboard tester record what I type?

    No. Key presses are counted inside this page and are gone when you close or reload it. The only things saved on your device are the layout you picked and the double-typing setting.

    Which layout should I choose?

    ANSI 104 is the common full-size layout with a wide Enter key. ISO 105 has a tall Enter key and one extra key next to the left Shift. Tenkeyless 87 has no number pad. Mac matches Apple keyboards.
