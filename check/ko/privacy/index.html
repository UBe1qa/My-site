마이크, 카메라와 그 밖의 기기

마이크 소리, 녹음, 카메라 영상, 사진은 이용자의 브라우저 탭 안에서만 처리해요. 저희를 포함해 어디에도 전송하지 않아요. 녹음과 사진은 지우거나, 새로 만들거나, 탭을 닫을 때까지 탭의 메모리에만 있어요. 마이크와 카메라 권한은 단추를 눌렀을 때만 요청하고, 끄기를 누르거나 페이지를 떠나거나 탭을 가리면 꺼요.

누른 키, 마우스 움직임, 컨트롤러 입력은 결과를 보여 주려고 화면 안에서만 세요. 저장하지 않고 어디에도 보내지 않아요.

기기에 저장하는 정보

다음에도 같은 모습으로 보이게 설정 몇 가지를 브라우저에 남겨요. 브라우저의 사이트 데이터 지우기로 언제든 지울 수 있어요.

  • ck.layout: 고른 자판 배열.
  • ck.chatter: 채터링 기준(ms).
  • ck.dblclick: 더블클릭 의심 기준(ms).
  • ck.lang: 다른 언어판 안내 띠를 닫았거나 눌렀다는 것. 띠를 다시 띄우지 않으려고 써요.
  • ck.done(세션 저장소, 탭을 닫으면 사라져요): 이 탭에서 이미 해 본 테스트. 페이지를 옮겨 다녀도 불이 켜진 채로 남게 하려고 써요.

방문 통계

방문 통계는 Cloudflare Web Analytics로 봐요. 어느 페이지를 몇 번 봤는지, 페이지가 얼마나 빨리 떴는지, 브라우저 종류, 페이지에서 느렸던 곳 같은 성능 정보예요. Cloudflare 설명으로는 쿠키나 기기 저장소를 쓰지 않아요. 기기에서 나온 소리·영상·입력과 테스트에서 고른 설정은 여기에 실리지 않아요. Cloudflare Web Analytics에서 볼 수 있어요.

광고

이 사이트는 Google 애드센스로 광고를 보여 줘요. Google을 비롯한 광고 회사는 쿠키를 써서 이 사이트나 다른 사이트에 방문한 기록을 바탕으로 광고를 고를 수 있어요. 광고 때문에 Google 같은 제3자가 이용자 브라우저에 쿠키를 넣거나 읽을 수 있고, 웹 비콘(눈에 보이지 않는 작은 이미지) 같은 기술로 정보를 모을 수 있어요. Google이 이 정보를 어떻게 쓰는지는 Google 파트너 사이트에서 Google이 데이터를 사용하는 방식에 있어요. 맞춤 광고는 Google 광고 설정에서 끌 수 있어요.

글꼴과 서버 기록

글꼴은 이 사이트에서 직접 보내요. 글꼴을 받으려고 다른 곳에 접속하지 않아요. 사이트는 Cloudflare에서 제공되고, Cloudflare는 서비스를 안전하게 운영하려고 접속 IP 같은 기본 기록을 잠시 남길 수 있어요. 소리, 영상, 입력은 받지 않아요.
