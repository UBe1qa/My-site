프롬프트는 AI에게 주는 설명이에요. 한국어로 고르면 영어 문장으로 바꿔 드리고, 그 조합으로 실제로 만든 결과도 옆에 보여 드려요. 복사해서 힉스필드에 붙여 넣으면 끝.

완성된 프롬프트

칸 하나만 바꿔도 이렇게 달라져요

⑤ 빛만 바꾸고 나머지 다섯 칸은 그대로 둔 결과예요. 셋 다 Soul 2.0으로 직접 만들었어요.

얼굴이 조금씩 다른 게 보이나요? 인물 설명을 똑같이 써도 뽑을 때마다 얼굴이 달라져요. 같은 얼굴을 계속 쓰려면 Soul ID가 필요한 이유예요.

같은 사진, 카메라만 바꾸면

위의 아침 햇살 사진을 시작 장면으로 넣고, 동작 문장은 그대로 둔 채 ② 카메라만 바꿨어요. Kling 3.0 · 720p · 5초 · 소리 끔.

잘 나오는 프롬프트의 규칙

이렇게 써요

  • 사진은 순서대로누가 → 입은 것 → 어디서 → 무엇을 → 빛 → 카메라·분위기
  • 영상은 동작 하나 + 카메라 하나사진에 이미 있는 옷·배경은 다시 쓰지 않아요.
  • 구체적인 말로빛 방향, 렌즈 35mm, 옷 소재처럼 눈에 보이는 걸 적어요.
  • 짧게 시작해서 하나씩 늘리기한 번에 하나만 바꿔야 뭐가 효과 있었는지 알아요.

이건 피해요

  • 막연한 말만 쓰기cinematic, beautiful 대신 빛·색·렌즈로 풀어 써요.
  • 영화·감독·작가 이름으로 스타일 지정원하는 결과가 안 나오고 거부되기도 해요.
  • 5초 영상에 동작 여러 개움직임이 뭉개지고 어색해져요.
  • 실존 인물, 노출, 미성년자생성이 거부되고 크레딧만 날릴 수 있어요.
