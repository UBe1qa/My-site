추가 크레딧은 90일

실패하면 돌려줘요

생성·업스케일이 실패하면 몇 분 안에 자동으로 돌려줘요. 결과가 마음에 안 드는 건 안 돌려줘요.

환불은 7일, 안 썼을 때만

첫 결제 후 7일 안에 크레딧을 하나도 안 썼을 때만 환불돼요. 자동 갱신된 결제는 환불 안 돼요.

무료는 워터마크

  • 밝고 선명한 사진, 가로세로 960px 이상
  • 정면, 옆, 비스듬히 — 여러 각도
  • 무표정, 미소, 웃음 — 여러 표정
  • 실내 빛과 자연광을 섞어서
  • 전신 사진 1장 이상

  • 선글라스, 모자, 마스크, 스카프
  • 얼굴에 짙은 그림자

  • 얼굴이 잘린 사진
  • 같은 사진 여러 장, 과한 표정

프롬프트

칸마다 하나씩 고르면 영어 프롬프트가 완성돼요

프롬프트는 AI에게 주는 설명이에요. 영어가 더 안정적이라, 한국어로 고르면 영어 문장으로 바꿔 드려요. 복사해서 붙여 넣으면 끝.

완성된 프롬프트

칸 하나만 바꿔도 이렇게 달라져요

⑤ 빛만 바꾸고 나머지 다섯 칸은 그대로 둔 결과예요. 셋 다 Soul 2.0으로 직접 만들었어요.

얼굴이 조금씩 다른 게 보이나요? 인물 설명을 똑같이 써도 뽑을 때마다 얼굴이 달라져요. 같은 얼굴을 계속 쓰려면 Soul ID가 필요한 이유예요.

같은 사진, 카메라만 바꾸면

위의 아침 햇살 사진을 시작 장면으로 넣고, 동작 문장은 그대로 둔 채 ② 카메라만 바꿨어요. Kling 3.0 · 720p · 5초 · 소리 끔.

잘 나오는 프롬프트의 규칙

이렇게 써요

  • 사진은 순서대로누가 → 입은 것 → 어디서 → 무엇을 → 빛 → 카메라·분위기
  • 영상은 동작 하나 + 카메라 하나사진에 이미 있는 옷·배경은 다시 쓰지 않아요.
  • 구체적인 말로빛 방향, 렌즈 35mm, 옷 소재처럼 눈에 보이는 걸 적어요.
  • 짧게 시작해서 하나씩 늘리기한 번에 하나만 바꿔야 뭐가 효과 있었는지 알아요.
