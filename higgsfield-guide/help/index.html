잘 안 나올 때 이렇게 고쳐요

초보가 가장 많이 막히는 여덟 가지예요. 증상을 누르면 원인과 해결법이 보여요.

얼굴이 매번 달라져요인물

왜 그럴까

글 설명에만 의존하거나, 얼굴이 화면에서 너무 작거나, 모델·프리셋을 자주 바꿔서예요.

이렇게

  • Soul ID를 만들어 Character 탭에서 고르기
  • 얼굴이 크게 나오는 구도(상반신)로
  • 모델과 프리셋을 하나로 고정
피부가 플라스틱처럼 매끈해요인물

왜 그럴까

흠 없는 얼굴을 만들면 오히려 AI티가 나요.

이렇게

  • 인물 설계에서 피부 상태(주근깨, 피부결) 넣기
  • 프롬프트에 natural skin texture 넣기
  • 영상은 사람 표현에 강한 Kling 3.0으로
사진에 인스타 화면 틀이 같이 그려져요사진

왜 그럴까

프롬프트에 Instagram post처럼 앱 이름을 쓰면, 아이디·버튼까지 있는 인스타 화면을 통째로 그려요. 이 페이지 예시를 만들다 실제로 겪은 일이에요.

이렇게

  • 앱 이름 대신 사진 느낌만 적기: casual everyday snapshot
  • 'post', 'story', 'feed' 같은 말도 빼기
  • 이미 나왔다면 Inpaint로 틀 부분만 지우기
손가락이 이상해요사진

왜 그럴까

손 동작을 복잡하게 설명하면 AI가 헷갈려요.

이렇게

  • 손이 적게 나오는 허리 위 구도로
  • 동작 대신 손의 시작·끝 위치만 적기
  • 손 모양 참고 사진을 같이 넣기
움직임이나 눈빛이 어색해요영상

왜 그럴까

한 클립에 동작을 여러 개 넣었거나, 영상이 너무 길어서예요.

이렇게

  • 동작 하나, 카메라 움직임 하나만
  • 20초 넘으면 나눠 만들고 이어 붙이기
  • 카메라는 속도와 끝 장면까지 적기
입 모양이 목소리와 안 맞아요소리

왜 그럴까

영상과 소리를 따로 만들어 편집으로 합쳤을 때 자주 생겨요.

이렇게

  • Lipsync Studio에서 사진 + 목소리로 만들기
  • 음성을 먼저 만들고, 정면·조명 고른 사진 쓰기
  • 여러 명이 말하는 장면은 피하기
생성이 거부돼요규칙

왜 그럴까

노출, 실존 인물·유명인, 미성년자로 보이는 표현은 막혀요.

이렇게

  • 가상 인물로, 성인임이 분명하게
  • 유명인 이름을 빼고 외모를 묘사로
  • 옷차림 표현을 바꿔 다시 시도
크레딧이 너무 빨리 줄어요크레딧

왜 그럴까

연습을 1080p나 비싼 모델(Seedance, Veo, Cinema Studio)로 하고 있어서예요.

이렇게

  • 사진으로 확정한 뒤에만 영상
  • Kling 3.0 · 720p · 5초로 연습
  • 확정된 것만 고화질로, 생성 버튼 옆 숫자 확인
