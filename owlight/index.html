장면을 눌러 보세요

웹으로 그린 미리 보기예요. 실제 앱 화면은 바로 아래에 있어요.

실제 앱에서는 이렇게 보여요

지금 쓰는 창만 또렷하게

  • 지금 쓰는 창은 또렷하게 두고, 나머지 화면엔 색조나 흐림을 입혀요. 색과 강도는 고를 수 있어요.
  • 최근 창을 다섯 개까지 밝게 둘 수 있어서 넓은 화면에서도 편해요.
  • 전체 화면과 데스크톱(스페이스) 전환 중에는 방해하지 않아요.

한 번에 차분한 바탕화면

  • 바탕화면 아이콘 위로 커튼을 드리워요. 열어 둔 창은 그 위에 그대로 보이고, 연결된 모든 디스플레이에 쳐져요.
  • 천천히 흐르는 오로라(6가지), 풍경 그림 10장, 반투명 유리, 단색, 내 사진 중에서 골라요.
  • 큰 시계와 짧은 문구(“5분 뒤 돌아옵니다”, 발표 제목)도 띄울 수 있어요.

커튼에 들어 있는 풍경 그림 10장

풍경 그림 10장은 AI 이미지 생성 도구로 만들었어요. 앱 안에 들어 있고, 앱이 그림을 새로 만들지는 않아요.

깨어 있어야 할 때만 깨어 있게

  • 15분부터 4시간까지, 또는 끌 때까지 컴퓨터가 잠들지 않게 지켜요. 디스플레이까지 켜 둘지도 골라요.
  • 배터리가 정한 수준 아래로 내려가면 알아서 멈춰요.

자동 잠자기만 막아요

  • 덮개를 닫거나 직접 잠자기를 고르면 잠들어요.
  • 배터리가 아주 적거나 열이 너무 높아도 잠들어요.
  • 이미 잠든 컴퓨터를 시간표가 깨우지는 않아요.

한 번 정해 두면 알아서 켜지고 꺼져요

충전기를 꽂았을 때, 정한 앱이 돌 때, 요일별 시간표에 맞춰 스스로 움직여요.

예시
  1. 오전 9:00

    평일 시간표가 되면

    불침번이 켜져요

  2. 오전 10:30

    회의 앱이 켜지면

    커튼이 쳐져요

  3. 오후 2:00

    몰입 세션 25분을 시작하면

    후광이 켜지고, 끝나면 꺼져요

  4. 오후 5:40

    배터리가 20% 아래로 내려가면

    불침번이 알아서 멈춰요

몰입 세션: 기록이 남는 몰입

시간을 정하면 고른 기능이 켜지고, 끝나면 꺼져요. 시간이 다 되면 알림으로 알려 주고, 오늘 몰입한 시간과 마친 세션 수를 한눈에 볼 수 있어요.

직접 켤 땐 단축키 한 번

모든 기능과 장면, 몰입 세션에 전역 단축키를 달 수 있어요. 단축어, 런처, 스크립트에서는 이런 링크로 불러요.

자주 묻는 질문

덮개를 닫아도 깨어 있나요?

아니요. 불침번은 자동 잠자기만 막아요. 덮개를 닫거나, 잠자기를 직접 고르거나, 배터리가 아주 적거나, 열이 너무 높으면 컴퓨터는 그대로 잠들어요. 시간표가 잠든 컴퓨터를 깨우지도 않아요.

모니터를 여러 대 써도 되나요?

네. 커튼은 연결된 모든 디스플레이에 쳐져요. 후광은 모든 디스플레이에 쓸지 고를 수 있고, 특정 앱에서는 꺼지게 할 수도 있어요.

메뉴 막대에 부엉이가 안 보여요.

노치나 꽉 찬 메뉴 막대에 가려졌을 수 있어요. 앱을 다시 열면 설정 창이 열리고, 거기서 모든 기능을 켜고 끌 수 있어요. Dock에는 아이콘이 없어요.
